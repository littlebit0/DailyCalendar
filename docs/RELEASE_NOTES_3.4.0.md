# DailyCalendar 3.4.0 릴리스 노트

## 릴리스 기준

- 3.3.1과 비교한 변경입니다.
- 공개 iOS/macOS 앱과 위젯의 버전 및 빌드는 `3.4.0 (3.4.0)`입니다.
- 새 iOS Transporter 제출 파일만 `3.4.0 (3.4.1)`을 쓰고, macOS 제출 파일은 그대로 둡니다.
- Android Release APK의 버전과 코드는 `3.4.0 (340)`입니다.
- Windows에는 지금까지의 최신 변경사항을 반영하지 않았습니다. 공유 Flutter
  코드나 버전 설정이 바뀌었더라도 Windows 반영, 빌드, 검증, 업데이트를 마쳤다는
  뜻은 아닙니다. 이번 릴리스에는 새 Windows 설치 파일이 없습니다.

## Linux 배포 추가 (2026-09-11)

- Ubuntu/Debian 데스크톱용 `daily-linux-3.4.0-1-amd64.deb`와
  `daily-linux-3.4.0-1-arm64.deb`를 추가했습니다.
- 한 번 설치하면 서명된 APT 저장소와 Daily 전용 업데이트 타이머를 등록합니다.
  타이머는 약 6시간마다 업데이트를 확인합니다. 앱이 실행 중이거나 패키지가
  고정돼 있거나 서명·네트워크 오류가 나면 기존 버전을 유지합니다. 사용자 일정과
  설정은 지우지 않습니다.
- Linux GTK 실행부, 데스크톱 Google OAuth, 사용자 세션의 예약 알림을 연결했습니다.
  DB/동기화 스키마와 다른 플랫폼의 설치 파일은 바꾸지 않았습니다.
- amd64/arm64 Release 빌드와 공개 APT 다운로드·해시 검증을 통과했습니다.
  amd64에서는 서명 오류 거부, 실행 중 업데이트 연기, hold/mask 유지, 설치·업데이트·
  제거·purge, SQLite 파일 보존을 검증했습니다. 실제 데스크톱에서 앱 실행, Google
  로그인, 알림 전달은 검증하지 않았습니다.
- [amd64 설치 파일](https://github.com/littlebit0/DailyCalendar/releases/download/v3.4.0/daily-linux-3.4.0-1-amd64.deb)
  · [arm64 설치 파일](https://github.com/littlebit0/DailyCalendar/releases/download/v3.4.0/daily-linux-3.4.0-1-arm64.deb)
- [Linux 설치 및 지원 범위](https://github.com/littlebit0/DailyCalendar/blob/main/docs/LINUX_DISTRIBUTION.md)

## 일정 이동과 순서

- 월간·주간·일간 화면과 하루보기에서 일정의 날짜 이동과 날짜별 수동 순서를 개선했습니다.
- 2026-09-07 iOS/Android 교체 파일에서는 두 가지 문제를 고쳤습니다. 설정의 분류
  손잡이를 길게 눌러도 순서 변경이 시작되지 않던 문제와 아래쪽으로 옮긴 순서가
  잘못 저장되던 문제입니다. macOS 공개 파일은 이번에 교체하지 않았습니다.
- 완료한 일정도 직접 옮길 수 있고, 드래그하는 동안 일정의 제목과 분류색을 그대로 보여 줍니다.
- 일정을 끌면 원래 자리와 놓을 자리를 비워 주는 애니메이션이 나오고, 대상 화면
  크기에 맞춰 드래그 UI가 바뀝니다. 이동을 저장할 때 화면이 깜빡이거나 일정이
  잠시 원래 위치로 돌아가던 현상을 고쳤습니다.
- iOS/Android에서 하루보기 팝업 밖으로 일정을 끌면 월간 달력 전체가 보입니다.
  다시 팝업 안으로 가져오면 일정 크기와 표시가 원래대로 돌아옵니다.
- macOS에서는 달력과 오른쪽 하루보기 사이를 양방향으로 옮길 수 있습니다. 표시
  크기 전환, 포인터 위치, 배경 깜빡임도 바로잡았습니다.
- 주간·일간 스케줄에서는 일정을 30분 단위로 옮기고 소요시간은 그대로 둡니다.
  스케줄 위에서는 시간 위치 힌트를 보여 주고, 사이드바로 옮기면 시간은 유지한 채
  선택한 날짜로 옮깁니다.

## 완료 표시와 조작

- 일정을 더블클릭하거나 더블탭하면 완료와 미완료를 전환합니다. 월간 막대, 주간·일간
  목록, 스케줄의 시간·종일 일정, 하루보기, 빠른 보기, 검색 결과에서 모두 동작합니다.
- 한 번 클릭하면 기존처럼 상세보기를 열거나 날짜를 고르고, 길게 누르면 드래그합니다.
  더블탭을 가려내야 해서 한 번 클릭에는 짧은 대기 시간이 있습니다.
- 완료한 일정도 제목, 배경, 강조선에 분류 색상을 그대로 쓰고, 테마에 맞는 한 줄
  취소선으로 구분합니다. Apple/Android 위젯에서도 분류 색상을 유지합니다.
- 완료 상태는 제목이 아니라 일정 ID와 반복 발생 단위로 처리합니다.
  공휴일, 시스템 일정, 읽기 전용 일정은 바꾸지 않습니다.

## 화면과 탐색

- 첫 화면 선택지를 빠른 보기, 주, 월, 일 네 가지로 합치고 설정 동기화에 넣었습니다.
- 빠른 보기에서는 월간 설정과 상관없이 좌우로 밀어 월을 넘깁니다. macOS 마우스
  한 틱, 빠른 연속 입력, 목록 세로 스크롤을 함께 처리합니다.
- 일간 스케줄은 날짜를 상단에 한 번만 보여 주고, 주말·공휴일 색상은 요일 글자에만
  씁니다. 주간 화면의 공휴일과 오늘 날짜 요일 색상도 바로잡았습니다.
- macOS에서 마우스 휠이 기본 페이지 스크롤과 충돌하거나 연속 틱이 빠지던 문제를 고쳤습니다.
- 모바일 하단 조작부를 하나로 합치고, 좁은 화면에서 설정 제목·설명·선택 컨트롤
  배치를 개선했습니다. Apple 플랫폼에서는 AI 기능을 Siri로 따로 표기합니다.

## Android

- 휴대폰과 태블릿의 조작부, 반응형 화면, 캘린더와 하루보기 드래그를 다듬었습니다.
- Google 로그인 구성을 점검했습니다. 자동 복원이나 백업 중에 사용자가 요청하지
  않은 대화형 로그인 창이 열리던 문제를 고쳤습니다.
- Android 일정 알람, 권한 처리, 예약 갱신·삭제, 재부팅 후 복원, 중지와 다시 알림을
  구현했습니다. 알람이 실제로 울리는지는 OS·제조사 정책과 사용자 권한에 따라 다릅니다.
- 위젯 높이에 맞춘 주간/월간 표시, 연속 일정 막대, Todo와 테마 갱신을 개선했습니다.
- Android에서는 Siri, Apple 로그인, AlarmKit을 제공하는 것처럼 표시하지 않습니다.

### Android 배포 서명 변경

- 기존 배포 개인키를 쓸 수 없어 새 배포키로 APK를 만들었습니다.
- 그래서 기존 공개 3.3.1 APK 위에 덮어써 설치할 수 없습니다. 앱을 지우면 로컬 데이터도
  지워지므로 먼저 백업하고 복원할 수 있는지 확인해야 합니다.
- 새 키의 Google Android OAuth 등록은 2026-09-07에 마쳤습니다. 실제 스마트폰
  로그인은 아직 검증하지 못했고, 설정이 반영되기까지 시간이 걸릴 수 있습니다.
  로컬 모드는 계정 없이 쓸 수 있습니다. 기존 OAuth 클라이언트는 그대로 둡니다.
- 키 전환 기준은 [Android 서명 안내](https://github.com/littlebit0/DailyCalendar/blob/main/docs/ANDROID_SIGNING.md)에 자세히 적었습니다.

## 검증 및 배포 범위

- Flutter 전체 자동 테스트 372개(기존 건너뜀 1개)와 정적 분석을 통과했습니다.
- 분류 손잡이를 실제 포인터로 조작하는 위젯 테스트에서 양방향 이동, 인접 순서 변경,
  설정 재진입, 분류 속성 보존을 확인했습니다.
- 플랫폼 구성 테스트 12개와 버전 설정 검사를 통과했습니다.
- 직전 macOS/iPhone 17/Android 테스트 앱 업데이트에서 데이터가 보존되는 것을 확인했습니다.
- Windows에는 최신 변경을 반영하지 않았고, 실제 OS 빌드·검증과 설치가 남아 있습니다.
- 자동 테스트를 통과했다고 실제 로그인, 알람 소리·진동, 모든 위젯 호스트를 검증한
  것은 아닙니다. 이번 배포 작업에서는 앱을 자동으로 실행하지 않았습니다.
- 새 키로 만든 Android Release APK의 빌드와 v2 서명 검증을 통과했습니다. 패키지,
  버전/코드, arm64-v8a/armeabi-v7a/x86_64, 운영 분석·버그 제보 주소가 들어 있는지 확인했습니다.
- 서명 설정 테스트 2개, 정적 분석, 배포 워크플로 YAML 구문 검사를 통과했습니다.
