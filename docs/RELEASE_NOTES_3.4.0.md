# DailyCalendar 3.4.0 릴리스 노트

## 릴리스 기준

- 비교 기준: 3.3.1
- 공개 iOS/macOS 앱·위젯 버전 및 빌드: `3.4.0 (3.4.0)`
- 새 iOS Transporter 제출용만 `3.4.0 (3.4.1)`이며 macOS 제출 파일은 유지합니다.
- Android Release APK 버전/코드: `3.4.0 (340)`
- **Windows에는 지금까지의 최신 변경사항이 미적용 상태입니다.** 공유 Flutter
  코드나 버전 설정이 변경되었어도 Windows 반영·빌드·검증·업데이트 완료를
  뜻하지 않습니다. 이번 릴리스에 새 Windows 설치 파일은 포함하지 않습니다.

## 일정 이동과 순서

- 월간·주간·일간 및 하루보기에서 일정 날짜 이동과 날짜별 수동 순서를 개선했습니다.
- 2026-09-07 iOS/Android 교체 파일에는 설정의 분류 손잡이를 길게 눌러도
  순서 변경이 시작되지 않거나 아래 방향 이동이 잘못 저장되던 문제를 수정했습니다.
  macOS 공개 파일은 이번 교체 대상이 아닙니다.
- 완료된 일정도 직접 이동할 수 있고, 드래그한 일정의 제목·분류색이 유지됩니다.
- 기존 자리와 삽입 위치를 비워 주는 애니메이션, 대상 화면 크기에 맞는 드래그
  UI 전환을 적용했습니다. 이동 저장 시 깜빡임과 원래 위치로 잠시 돌아가는
  현상을 보정했습니다.
- iOS/Android 하루보기 팝업 밖으로 드래그하면 월간 달력 전체를 확인할 수
  있으며, 팝업 안으로 돌아오면 일정 크기와 표시를 복원합니다.
- macOS 달력과 우측 하루보기 사이에서 양방향 이동을 지원하고, 표시 크기
  전환·포인터 위치·배경 깜빡임을 보정했습니다.
- 주·일간 스케줄은 30분 단위로 이동하며 일정 소요시간을 유지합니다.
  스케줄에서는 시간 위치 힌트를 표시하고, 사이드바로 옮길 때는 시간은
  유지한 채 선택된 날짜로 이동합니다.

## 완료 표시와 조작

- 일정 더블클릭/더블탭으로 완료·미완료를 전환합니다. 월간 막대, 주·일 목록,
  스케줄의 시간/종일 일정, 하루보기, 빠른 보기와 검색 결과에 적용합니다.
- 단일 클릭의 기존 상세보기/날짜 선택과 길게 누르는 드래그는 유지합니다.
  더블탭 판별을 위해 단일 클릭에는 짧은 대기 시간이 있습니다.
- 완료 일정은 제목·배경·강조선의 분류 색상을 유지하고 테마에 맞는 한 줄
  취소선으로 구분합니다. Apple/Android 위젯도 분류 색상을 유지합니다.
- 제목이 아닌 일정 ID와 반복 발생 단위로 완료 상태를 처리합니다.
  공휴일·시스템·읽기 전용 일정은 변경하지 않습니다.

## 화면과 탐색

- 첫 화면 선택을 빠른 보기/주/월/일 네 가지로 통합하고 설정 동기화에 반영했습니다.
- 빠른 보기는 월간 설정과 관계없이 좌우 슬라이드로 월을 이동합니다.
  macOS 마우스 한 틱·빠른 연속 입력과 목록 세로 스크롤을 함께 처리합니다.
- 일간 스케줄 날짜는 상단에 한 번만 표시하고 요일 텍스트에만 주말·공휴일
  색상을 적용합니다. 주간 공휴일과 오늘 날짜의 요일 색상도 보정했습니다.
- macOS 마우스 휠과 기본 페이지 스크롤의 충돌, 연속 틱 누락을 수정했습니다.
- 모바일 통합 하단 조작부, 좁은 화면의 설정 제목·설명·선택 컨트롤 배치를
  개선했습니다. Apple 플랫폼의 AI 기능 표기는 Siri로 구분합니다.

## Android

- 휴대폰/태블릿의 조작부와 반응형 화면, 캘린더와 하루보기 드래그를 보완했습니다.
- Google 로그인 구성을 점검하고 사용자가 요청하지 않은 대화형 로그인
  창이 자동 복원·백업 과정에서 열리지 않도록 수정했습니다.
- Android 일정 알람, 권한 처리, 예약 갱신·삭제·재부팅 복원과 중지/다시 알림을
  구현했습니다. 실제 울림은 OS·제조사 정책과 사용자 권한에 영향을 받습니다.
- 위젯 높이에 따른 주간/월간 표시, 연속 일정 막대, Todo 및 테마 갱신을 개선했습니다.
- Siri/Apple 로그인/AlarmKit을 Android에서 제공한다고 표시하지 않습니다.

### Android 배포 서명 변경

- 기존 배포 개인키를 사용할 수 없어 새 배포키로 APK를 만들었습니다.
- 기존 공개 3.3.1 APK에는 덮어쓰기 설치할 수 없습니다. 삭제 시 로컬 데이터가
  제거되므로 먼저 백업과 복원 가능 여부를 확인해야 합니다.
- 새 키의 Google Android OAuth 등록은 2026-09-07 완료했습니다. 실제
  스마트폰 로그인은 검증 대기 중이며, 설정 반영에 시간이 걸릴 수 있습니다.
  로컬 모드는 계정 없이 사용할 수 있습니다. 기존 OAuth 클라이언트는 유지합니다.
- 자세한 키 전환 기준은 [Android 서명 안내](https://github.com/littlebit0/DailyCalendar/blob/main/docs/ANDROID_SIGNING.md)를 확인하세요.

## 검증 및 배포 범위

- Flutter 전체 자동 테스트 372개 통과(기존 건너뜀 1개), 정적 분석 통과.
- 분류 손잡이의 실제 포인터 위젯 테스트로 양방향 이동, 인접 순서 변경,
  설정 재진입 및 분류 속성 보존을 확인했습니다.
- 플랫폼 구성 테스트 12개 및 버전 설정 검사 통과.
- 직전 macOS/iPhone 17/Android 테스트 앱 업데이트에서 데이터 보존 확인.
- Windows는 최신 변경 미적용이며 실제 OS 빌드·검증과 설치가 남아 있습니다.
- 자동 테스트 통과는 실제 로그인, 알람 소리·진동, 모든 위젯 호스트 검증을
  대체하지 않습니다. 이번 배포 작업에서 앱을 자동 실행하지 않습니다.
- 새 키로 Android Release APK 빌드 및 v2 서명 검증 통과. 패키지, 버전/코드,
  arm64-v8a/armeabi-v7a/x86_64와 운영 분석·버그 제보 주소 포함을 확인했습니다.
- 서명 설정 테스트 2개, 정적 분석 및 배포 워크플로 YAML 구문 검사 통과.
