# Daily 3.6.0

## 학사 관리와 시간표

- 설정의 학사 관리 화면에서 학사 정보, 학교 LMS 연결, 학사일정, 시간표 설정을 함께 관리합니다.
- 4년제 대학을 이름이나 초성으로 검색해 Google 계정에 등록합니다. 통합 캠퍼스는 같은 학교로 표시합니다.
- 상명대학교 서울·천안, 단국대학교 죽전·천안, 전남대학교 광주·여수의 학사일정 추가와 시간표를 지원합니다.
- 연도·학기 목록과 별도 강의 검색 화면을 추가했습니다. 검색창은 위에 고정되고, 캠퍼스와 이수구분으로 거를 수 있습니다. 강의를 펼치면 과목코드, 분반, 강의실, 비고를 보고 바로 추가합니다.
- 시간표와 학사 설정은 Google Drive에 동기화합니다. 주간·일간 달력에는 해당 학기 기간의 수업만 나타납니다.

## 학교 LMS 연결

- 상명대학교 공식 로그인 화면에서 인증하면 과제 마감과 퀴즈 일정을 가져옵니다.
- LMS 일정을 저장할 분류를 직접 만든 분류 중에서 고릅니다. 이미 연결된 일정과 새 일정에 같은 분류를 적용하고 동기화합니다.
- 학교에서 받은 제목, 마감, 제출 상태와 사용자가 단 메모, 알림, 완료 표시를 따로 보존합니다.
- 앱을 시작하거나 다시 열 때, 그리고 사용 중에는 5분마다 학교 쪽 변경을 확인합니다. 즉시 푸시 방식은 아닙니다. 학교 인증이 만료되면 다시 로그인해야 합니다.
- 현재 LMS 연결은 상명대학교의 과제와 퀴즈만 지원합니다. 다른 학교 LMS와 온라인 강의 진도 연동은 들어 있지 않습니다.

## 사용성과 동기화 개선

- 시간표, 빠른보기, 주/월/일 달력, 설정 사이의 전환과 화면 전환 애니메이션을 다듬고, macOS 상단 메뉴 정렬을 고쳤습니다.
- 어두운 테마에서 팝업 경계와 학사 정보 선택 영역이 더 잘 보입니다.
- 백업과 복원을 하나의 동기화 작업으로 합쳤고, 요청은 차례대로 처리합니다.
- 시작 동기화와 데이터 마이그레이션 때 모든 일정을 필요 없이 다시 처리하던 문제를 고쳤습니다.

## 업데이트 안내

- Drive v2를 그대로 쓰고, LMS 데이터와 소유권 정보를 담는 DB 스키마 9를 사용합니다. 연결된 기기는 모두 3.6.0으로 함께 업데이트해 주세요.
- GitHub에 올린 iOS IPA와 macOS DMG는 공개 빌드용 미서명 산출물입니다. App Store/Transporter용 서명 패키지와는 다릅니다.
- Android APK는 기존 배포 서명을 그대로 씁니다. 예전에 다른 인증서로 설치한 앱은 덮어쓰기가 막힐 수 있습니다.
- GitHub 릴리스와 App Store 심사·출시는 따로 진행합니다.
