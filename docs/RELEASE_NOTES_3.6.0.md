# Daily 3.6.0

## 학사 관리와 시간표

- 설정의 **학사 관리**에서 학사 정보, 학교 LMS 연결, 학사일정, 시간표 설정을 한곳에서 관리합니다.
- 4년제 대학을 이름·초성으로 검색해 Google 계정에 등록하고, 통합 캠퍼스는 같은 학교로 표시합니다.
- 상명대학교 서울·천안, 단국대학교 죽전·천안, 전남대학교 광주·여수의 학사일정 추가와 시간표를 지원합니다.
- 연도·학기 목록, 별도 강의 검색 화면, 고정 검색창과 캠퍼스·이수구분 필터를 제공합니다. 강의를 펼쳐 과목코드·분반·강의실·비고를 확인하고 추가할 수 있습니다.
- 시간표와 학사 설정을 Google Drive에 동기화하며, 주·일간 달력에는 해당 학기 기간의 수업만 표시합니다.

## 학교 LMS 연결

- 상명대학교 공식 로그인 화면에서 인증하면 과제 마감과 퀴즈 일정을 가져옵니다.
- 개인이 만든 분류 중 LMS 일정의 저장 분류를 선택할 수 있습니다. 기존 연결 일정과 새 일정에 같은 분류를 적용하고 동기화합니다.
- 학교의 제목·마감·제출 상태와 개인 메모·알림·완료 표시를 구분해 보존합니다.
- 앱 시작·복귀 및 사용 중 5분 간격으로 학교 변경을 확인합니다. 즉시 푸시 방식은 아니며, 학교 인증 만료 시 재로그인이 필요합니다.
- 현재 LMS는 상명대학교의 과제·퀴즈를 지원합니다. 다른 학교 LMS와 온라인 강의 진도 연동은 포함하지 않습니다.

## 사용성과 동기화 개선

- 시간표·빠른보기·주/월/일 달력·설정 전환과 macOS 상단 메뉴 정렬, 화면 전환 애니메이션을 개선했습니다.
- 어두운 테마의 팝업 경계와 학사 정보 선택 영역을 더 명확하게 표시합니다.
- 백업·복원을 하나의 동기화 작업으로 통합하고 요청을 순차적으로 처리합니다.
- 시작 동기화와 데이터 마이그레이션에서 불필요하게 모든 일정을 다시 처리하던 문제를 수정했습니다.

## 업데이트 안내

- Drive v2를 유지하며 LMS 데이터와 소유권 정보를 위한 DB 스키마 9를 사용합니다. 연결된 기기는 함께 3.6.0으로 업데이트해 주세요.
- GitHub의 iOS IPA와 macOS DMG는 공개 빌드용 미서명 산출물입니다. App Store/Transporter 서명 패키지와 다릅니다.
- Android APK는 기존 배포 서명을 유지합니다. 과거 다른 인증서로 설치된 앱은 덮어쓰기가 제한될 수 있습니다.
- GitHub 릴리스와 App Store 심사·출시는 별개입니다.
