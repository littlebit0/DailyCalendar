# Daily 2.7.3 릴리스 노트

## 바뀐 점

- 빠른 보기를 열기 전에 쓰던 주간, 월간, 일간 보기 버튼을 다시 누르면
  그 캘린더로 돌아갑니다. GitHub 이슈 #28을 고쳤습니다.
- 오른쪽 하루 일정 패널에서 일정 카드의 어느 곳을 눌러도 상세보기가 열립니다.
  수정 버튼과 삭제 버튼은 눈에 보이는 영역만큼 눌립니다. GitHub 이슈 #31을
  고쳤습니다.
- iOS, macOS, Android, Windows에서 사용자에게 보이는 버전을
  `2.7.3 (2.7.3)`으로 맞췄습니다.

## 플랫폼별 내부 버전

- iOS: `2.7.3 (2.7.3)`
- macOS: `2.7.3 (2.7.3)`
- Android: version name `2.7.3`, 정수 version code `273`
- Windows: 앱 표시 `2.7.3 (2.7.3)`, MSIX `2.7.3.3`

Android version code와 Windows MSIX 버전은 각 운영체제가 요구하는 형식을 따릅니다.

## 확인한 항목

- 주간, 월간, 일간 보기에서 각각 빠른 보기로 들어간 뒤 같은 보기로 돌아오는지
- 일정 카드의 위, 아래, 왼쪽, 오른쪽 가장자리를 눌러 상세보기가 열리는지
- 수정 버튼과 삭제 버튼의 클릭 영역 전체
- Flutter 정적 분석과 전체 테스트
- GitHub Actions의 Android, Windows 플랫폼 빌드
