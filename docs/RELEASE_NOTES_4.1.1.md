# DailyCalendar 4.1.1

4.1.0 이후 동기화 속도와 일정 화면 문제를 고친 긴급 패치입니다.

## 주요 변경

- Google Drive 동기화가 빨라졌습니다.
  - 일정 파일을 동시에 여러 개 주고받습니다.
  - 내용이 같은 파일은 다시 내려받지 않습니다.
  - 동기화 전 고정 3초 대기를 없앴습니다.
  - 요청 한도에 걸리면 잠시 기다렸다 다시 시도합니다.
- 동기화 중 캘린더가 깜빡이거나 보던 위치가 잠깐 이동하던 문제를 고쳤습니다.
- 동기화 배너가 나타나고 사라질 때 화면 전체가 위아래로 튀지 않게 했습니다.
- 일정 알람의 발동 시각을 여러 개 고를 수 있습니다(예: 30분 전 + 10분 전 + 정시).
- 자정을 넘는 일정을 다음 날에도 표시할지 일정마다 정할 수 있습니다.
- 하루 일정 시트
  - 아래로 끌어 닫는 기준을 완화했습니다.
  - 빠르게 튕겨도 닫히지 않던 문제를 고쳤습니다.
  - 좌우로 날짜를 넘길 때 방향에 맞게 밀려 들어오고, 로딩 표시가 깜빡이지 않습니다.
- 요일을 지정한 주간 반복(예: 격주 월·금)을 시작일 요일부터 계산합니다. 반복 일정을 며칠 옮기거나 중간 회차부터 나눠도 모든 회차가 같은 간격을 유지합니다.
- 주간 날짜 패널 머리글이 좁은 화면에서 넘치던 문제를 고쳤습니다.
- 일정 추가·수정 팝업의 하단 버튼(템플릿으로 저장·취소·저장)을 한 줄로 배치해, 휴대폰에서 버튼이 세로로 쌓이지 않습니다.
- 시간표 자산의 불필요한 공백을 없애 앱 용량을 줄였습니다. 시간표 내용은 같습니다.

## 같은 계정의 모든 기기를 업데이트해 주세요

이 버전은 Google Drive 일정 파일에 새 값을 씁니다. 같은 Google 계정으로 동기화하는 모든 기기를 4.1.1로 업데이트해 주세요. 4.1.0 이하 기기를 함께 쓰면 다음과 같이 됩니다.

- 알람 시각을 여러 개 고른 일정: 구버전 기기는 가장 이른 알람 하나만 울립니다. 구버전 기기에서 그 일정을 고쳐 저장하면 알람이 하나로 줄어듭니다.
- 다음 날 표시를 일정마다 끈 일정: 구버전 기기는 이 값을 모르고 기기 전체 설정을 따릅니다.
- 요일을 지정한 주간 반복 일정
  - 구버전 기기는 월요일 기준으로 주를 셉니다.
  - 그래서 시작일이 월요일이 아니거나, 반복을 옮기거나 나눈 일정은 구버전 기기에서 일부 회차가 1주 어긋나 보일 수 있습니다.
  - 구버전 기기에서 나눈 일정을 고쳐 저장하면 주 시작 정보가 지워집니다.

일정 자체가 지워지지는 않습니다. Windows 앱은 자동으로 업데이트합니다. Android, macOS, iPhone·iPad는 각 기기에서 직접 업데이트해 주세요.

## 배포 구분

Drive v2 일정·템플릿 파일 형식이 바뀌므로 Windows·Android 산출물과 Mac·iPhone 산출물을 함께 게시합니다.

## 동기화·저장 형식 변경

- 로컬 DB 스키마가 12에서 15로 올라갑니다. 앱을 처음 실행할 때 기존 데이터를 옮깁니다.
  - 13: 여러 알람 시각
  - 14: 내용이 같은 Drive 파일을 다시 받지 않기 위한 기기 안 사본(Drive에 올리지 않음)
  - 15: 일정별 다음 날 표시
- Drive v2 일정 파일(`daily-sync-v2-event-{eventId}.json`)
  - 알람 시각이 2개 이상일 때만 `alarmMinutesBeforeList`·`alarmCustomAtList`를 씁니다. 기존 `alarmMinutesBefore`·`alarmCustomAt`에는 대표 알람을 계속 씁니다.
  - `showOvernightOnFollowingDays`를 씁니다.
  - 반복 일정을 원래 시작 요일이 아닌 회차부터 나눈 경우 `recurrenceDetails` 안에 `weekStart`를 씁니다.
- 템플릿 파일(`daily-sync-v2-templates.json`)에 여러 알람 시각과 다음 날 표시 끔이 저장됩니다.
- 설정 동기화 문서의 전역 다음 날 표시(`calendarShowOvernightEventsOnFollowingDays`)는 이 버전부터 읽거나 쓰지 않습니다. 구버전 기기가 올린 값은 그대로 보존됩니다.

## 알려진 제한

- Mac App Store용 4.1.1은 4.1.0과 같이 Apple Silicon(M 시리즈) Mac 전용입니다.
- 구버전과 신버전 기기를 함께 쓸 때의 동작은 코드를 정적으로 확인하고 자동 테스트로 검증한 결과입니다. 실제 Google Drive와 여러 기기를 함께 쓰는 확인은 하지 않았습니다.
- Drive 동시 전송 개수(6개)에서 실제 계정의 요청 한도 응답 빈도는 측정하지 않았습니다.

## 검증

- 4.1.1 코드가 모두 들어간 main `ed87b35cc`의 CI(Platform Builds, 실행 42539411743) 작업 7개가 모두 통과했습니다: Dart 분석·전체 테스트, 시간표 테스트 3개, Android·Windows Debug 빌드, Apple LMS 세션 테스트. 이후 main에는 이 릴리스 노트만 추가됐습니다.
- macOS·iPhone 시뮬레이터·Android 에뮬레이터 테스트 앱으로 업데이트 후 데이터 보존, Drive 동기화, 여러 알람(Android 시스템 알람 예약·취소), 일정별 다음 날 표시, 하루 시트 날짜 이동을 확인했습니다.
- 그 테스트에서 찾은 문제 3건(#803~#805)을 고쳐 이 버전에 포함했습니다. 고친 뒤 실제 기기 동작은 확인하지 않았습니다.
