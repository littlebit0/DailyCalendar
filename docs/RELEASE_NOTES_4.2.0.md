# DailyCalendar 4.2.0

LMS 연동 학교를 늘리고, 스크롤·템플릿·로그인 문제를 고친 업데이트입니다.

## 바뀐 점

- LMS 연동을 학교 설정 목록 방식으로 바꾸고 6개 대학을 추가했습니다. 지원 학교는 상명대를 포함해 7곳입니다.
- 가천대 LMS에서 미개설 강좌(#) 카드를 건너뛰고, 진도율 열이 없는 학습 현황 표를 읽습니다.
- LMS 학습 콘텐츠를 더 정확히 읽습니다.
  - 잠긴 항목은 강좌 화면의 번호로 복구합니다.
  - 기간이 없는 학습은 설정의 기한 없는 학습 목록에 표시합니다.
  - 기한 없는 학습 중 요구 시간을 읽지 못한 항목은 계속 미해결로 집계합니다.
- 앱 화면이 다시 활성화된 뒤에 LMS 자동 재로그인을 실행합니다. 자동 복구 중에는 캘린더의 LMS 동기화 버튼을 숨깁니다.
- 상하 스크롤 달력이 스크롤 중 이전 달로 끌려가지 않게 고쳤습니다. 스크롤 중에 누른 '오늘로 이동' 요청도 무시하지 않습니다.
- 일정 템플릿 목록의 `…` 메뉴를 수정·삭제 버튼 두 개로 바꿨고, 이름 변경 메뉴는 없앴습니다.
- 템플릿 수정 화면에서 시작일·종료일 대신 기간(일수)만 편집합니다. 기간 일수는 달력 날짜 기준으로 계산해 서머타임 날짜에서 어긋나지 않습니다.
- 앱 안의 Siri 입력 버튼(하단 바, macOS 툴바)을 없앴습니다. Siri는 단축어로만 씁니다.
- Android에서 계정을 고른 뒤 `Account reauth failed`가 나오면 취소가 아니라 설정 오류로 안내합니다.
- iOS 조용한 승인이 시간 초과되어도 시작 동기화의 일시 실패로 처리합니다. 앱이 비활성인 동안 시간 초과된 시작 동기화는 앱으로 돌아온 뒤 한 번 다시 실행합니다.

## 동기화·저장 형식 변경

없습니다. Drive v2 파일 형식과 로컬 DB 스키마(15)는 4.1.1과 같습니다. 4.1.1 기기와 함께 써도 됩니다.

## 알려진 제한

- Mac App Store용 4.2.0은 4.1.1과 마찬가지로 Apple Silicon(M 시리즈) Mac에서만 실행됩니다.
- 새로 추가한 LMS 학교의 실제 계정 로그인과 동기화는 이 릴리스 전에 확인하지 못한 학교가 있을 수 있습니다. 학교별 동작은 앱에서 직접 확인해 주세요.

## 검증

- main `07e3492a6`의 CI(Platform Builds, 실행 43884035739)에서 Dart 분석·전체 테스트, 시간표 테스트 3개, Windows Debug 빌드, Apple LMS 세션 테스트가 통과했습니다. 같은 실행의 Android Debug 빌드는 Gradle 플러그인 저장소(plugins.gradle.org)에서 의존성을 받지 못해 실패했습니다. 코드 오류가 아니라 네트워크 오류입니다.
- 4.2.0 버전 올림 커밋 `f8e6aed62`로 Android `.aab`, iOS App Store `.ipa`, macOS App Store `.pkg`를 만들고 버전 4.2.0을 확인했습니다. 이 산출물을 실제 기기에 설치해 사용해 보지는 않았습니다.
