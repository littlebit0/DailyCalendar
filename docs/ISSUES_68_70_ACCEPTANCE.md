## 68: 원본 일정 UI 유지

같은 영역 안에서는 처음 집어 든 일정의 실제 크기와 내부 UI를 유지한다.
macOS 달력과 우측 하루보기 사이에서는 기존 양방향 크기·UI 전환을 유지하며,
목적지의 실제 일정 위젯을 사용한다. 분류색과 설정된 텍스트 정렬을 유지하고,
원래 영역으로 돌아오면 처음 집었던 UI로 부드럽게 복원한다.

- [ ] 월간에서 짧은 일정과 여러 날짜에 걸친 일정을 집어 이동한다.
- [ ] 목록 주간·일간 각각에서 날짜 이동과 같은 날짜 내 순서 변경을 확인한다.
- [ ] 스케줄 주간·일간 각각에서 짧은/긴 시간 일정 및 종일 일정을 이동한다.
- [ ] 드래그 중 폭·높이·모서리·패딩·배경·분류선·제목·시간·아이콘이 원본과 같다.
- [ ] 제목 가운데 정렬 및 기본 정렬이 각각 드래그 중에도 유지된다.
- [ ] 긴 제목, 줄바꿈, 말줄임, 글자 크기 3단계, 지원 언어별로 확인한다.
- [ ] 완료된 일정도 분류색과 취소선을 유지한 상태로 이동·순서 변경된다.
- [ ] macOS: 달력 → 우측 하루보기 → 달력, 반대 방향 모두 확대·축소가 부드럽게 이어진다.
- [ ] macOS: 같은 달력 안의 이동에서는 불필요한 축소가 없고, 경계 전환에서만 목적지 UI로 바뀐다.
- [ ] macOS: 경계를 반복 왕복하거나 애니메이션 도중 반대로 이동해도 갑자기 크기가 튀지 않는다.
- [ ] iOS/Android: 하루 전체보기 팝업 안 → 달력 → 팝업으로 돌아와도 원본 UI가 유지된다.
- [ ] 팝업 밖으로 이동하면 기존 달력 노출 동작이 유지되고, 복귀·취소하면 팝업이 돌아온다.
- [ ] 카드 중앙뿐 아니라 상단/하단/좌우 끝을 잡아도 잡은 지점이 포인터·손가락과 어긋나지 않는다.
- [ ] 원래 자리에 카드가 중복 표시되지 않고, 순서 삽입 공간이 기존처럼 움직인다.
- [ ] 드롭 직후 원위치로 잠시 돌아가거나 축소·깜빡임이 발생하지 않는다.
- [ ] 드래그 취소 시 원래 순서·날짜와 UI가 복원되고 일정이 중복 생성되지 않는다.
- [ ] 스케줄 시간 이동은 기존 30분 단위와 소요시간을 유지하고 시간 힌트가 정확하다.
- [ ] 날짜만 이동할 때는 시각·소요시간이 유지된다. 반복 일정의 적용 범위 선택도 유지된다.
- [ ] 드롭·취소 후 다른 날짜 선택, 일정 열기, 스크롤, 다음 드래그가 정상 동작한다.

## 70: 완료 취소선 대비

텍스트·분류색·배경은 유지하고 취소선 색만 변경한다. 글자와 배경 중
더 낮은 쪽의 명암 대비를 최대화하는 불투명 회색을 선택한다.
이는 단일 선에서 두 대비를 절충하는 기준이지, 모든 색 조합에서
동일한 높은 대비를 보장한다는 뜻은 아니다. 두 줄·외곽선은 추가하지 않는다.

- [ ] 월간, 목록 주간·일간, 스케줄 주간·일간의 완료 표시를 각각 확인한다.
- [ ] 빠른보기, 우측 하루보기, 하단 하루 전체보기, 일정 상세, 검색 결과를 확인한다.
- [ ] 드래그 중 완료선의 색·위치와 원본 일정의 완료선이 동일하다.
- [ ] 제목뿐 아니라 배경·분류 표시선도 완료 전의 분류색을 유지한다.
- [ ] 중앙 취소선 한 줄만 표시되며 두께·위치·정렬·레이아웃이 바뀌지 않는다.
- [ ] 완료 해제 시 취소선만 사라지고 일정의 내용·색·순서가 유지된다.
- [ ] 흰색/검정/근접 흰색·검정/중간 회색/노랑/빨강/파랑/초록 및 사용자 RGB로 확인한다.
- [ ] 다크 ↔ 화이트를 반복 전환했을 때 현재 테마에 맞게 선 색이 다시 계산된다.
- [ ] 완료 상태에서 분류색을 바꾼 뒤 모든 일정 화면에 새 대비가 반영된다.
- [ ] macOS·iOS·Android의 오늘 일정/달력/D-day 위젯을 지원 크기별로 확인한다.
- [ ] 위젯의 자동 테마/강제 테마, 크기 변경 후 제목 및 취소선이 정상 표시된다.
- [ ] Android 위젯: 긴 제목 말줄임, 큰 시스템 글자, 좁은 위젯에서도 취소선이 제목 영역을 벗어나지 않는다.
- [ ] 위젯 체크박스는 해당 일정만 변경하고 제목 클릭은 기존 상세 열기 동작을 유지한다.
- [ ] iOS 잠금화면 위젯은 시스템 색조 영향까지 실제 잠금화면에서 확인한다.
- [ ] #66 배경화면을 사용 중이면 새 이미지 생성 후 완료선 대비를 확인한다.

  [EnvironmentValues 공식 문서](https://developer.apple.com/documentation/SwiftUI/EnvironmentValues).
