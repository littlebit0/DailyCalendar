# DailyCalendar 4.0.0

## 주요 변경

- 학사정보 등록에 지역 지도·필터와 대학 교표를 추가하고, 지역에 맞는 분교를 자동 선택합니다.
- 대학 학사일정 연동 범위를 확대했습니다. 학교 시간표 검색은 검증 범위를 구분하여 10개 대학에서 유지합니다.
- 시간표의 교필·교선 표시, 학과 선택과 공식 전공제도 소속 분류를 개선했습니다.
- LMS 로그인 정보를 기기별 보안 저장소에만 저장하는 선택형 자동 로그인을 추가했습니다. 일정은 Google 계정으로 동기화되며 로그인 정보는 다른 기기로 보내지 않습니다.
- LMS 퀴즈 완료 상태와 직접 완료한 일정의 보존을 개선하고 반복 조회를 줄였습니다.
- 완료 취소선을 다크 모드에서 흰색, 밝은 모드에서 검정색으로 통일했습니다.
- 빠른 보기·시간표 전환, 대학 목록의 마우스 스크롤과 지역 전환 애니메이션을 개선했습니다. 실제 프레임률은 기기·디스플레이와 실행 상태에 따라 달라집니다.
- 시작 동기화의 상태 처리와 계측, 개인 분류 및 완료 상태의 동기화 보존을 개선했습니다.

## 대학 지원 범위

학교 시간표 검색 지원: 상명대학교, 단국대학교, 아주대학교, 중앙대학교, 이화여자대학교, 홍익대학교, 인하대학교, 부산대학교, 세종대학교, 서울대학교.

미완료 대학의 학교 시간표 검색은 잠정 미지원으로 표시합니다. 기존 학사일정, 저장한 시간표 및 직접 수업 추가는 유지합니다. 대학 전체 시간표 지원을 완료했다는 뜻은 아닙니다. 남은 원자료·분류 작업 및 단과대 선택 구조 통합 요구는 [이슈 #92](https://github.com/littlebit0/DailyCalendar/issues/92)에 기록했습니다. 단과대 주관 항목을 동일 단과대 안으로 통합하는 새 UI는 이 버전에 포함하지 않습니다.

LMS 연결은 현재 지원하는 학교에서만 사용할 수 있습니다. 자동 로그인은 설정한 기기에만 적용되며, 학교 정책에 따라 로그인하면 다른 기기의 LMS 세션이 로그아웃될 수 있습니다.

## 배포 구분

Drive v2와 DB 스키마 9를 유지합니다. GitHub 설치 파일과 Apple App Store 제출용 서명 파일은 별개입니다. Transporter 파일 생성은 Apple 업로드·심사 제출·스토어 공개를 의미하지 않습니다.

## 검증

제품 lib/test 정적 분석은 통과했습니다. 전체 Dart 검사는 최초 1,982개 통과·1개 건너뜀·29개 실패였으며, 오래된 취소선/UI 기대값 및 지역 제공자 테스트 설정의 11개 실패는 수정 후 해당 범위 재검증을 통과했습니다. 보류 원자료·스냅샷 검사 18건은 이슈 #92에 남아 있어 전체 검사 통과를 의미하지 않습니다. Apple 쿠키·비밀번호 입력·Siri 정책 검사와 iOS/macOS Release 아카이브·App Store 배포 서명 검증을 통과했습니다. GitHub Actions의 Windows·Android·iOS·macOS·Linux ARM64 배포 빌드가 통과했습니다. 사용자 결정에 따라 Linux AMD64는 3.6.0을 유지합니다. 전체 테스트가 필요한 AMD64 작업은 보류 원자료 실패로 출판 대상에서 제외했으며, 자동 APT 채널은 기존 3.6.0을 유지합니다. 전체 GitHub workflow 통과 주장은 아닙니다. 보류 대학의 원자료 검사와 실계정·실기기 전체 동작 확인을 완료했다고 주장하지 않습니다.

원격 전체 CI는 1,508개 통과·247개 실패·33개 건너뜀입니다. 실패243건은 Git 제외 `work/` 원자료/스냅샷 의존성으로 발생한 파일 누락이고, 나머지4건은 보류 대학의 기대값 차이입니다. 로컬 검사와 원격 재현성을 구분하며 인계 이슈 #92에서 함께 처리합니다. Android/Windows Debug 빌드는 별도로 통과했습니다.
