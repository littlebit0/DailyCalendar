# DailyCalendar 3.3.1 릴리스 노트

## 버전 정보

- 앱 표시 버전과 빌드: `3.3.1 (3.3.1)`
- Android 버전 이름과 코드: `3.3.1 (331)`
- Apple 앱 번들 ID: `com.littlebit0.daily`
- Apple 위젯 번들 ID: `com.littlebit0.daily.widgets`
- 비교 기준: `3.1.0`

## 바뀐 점

- 모든 일정에 Todo 완료 상태를 추가했습니다. 빠른 보기, 캘린더, 일정 상세,
  Apple 위젯에서 완료 상태를 바꿀 수 있습니다.
- 기존 사용자 데이터는 원격 복원, 안전 스냅샷, 검증, 원자적 교체 순서로
  마이그레이션합니다. 실패하면 원본 데이터를 그대로 둡니다.
- 일정 날짜 이동, 날짜별 수동 순서, 분류 순서, 분류 우선·시간 우선 정렬,
  공휴일 색상, 날짜 배경 설정을 추가했습니다.
- 반복 일정의 종료일이 빠지던 문제와 한 발생분의 Todo 완료가 다른 발생분에도
  적용되던 문제를 고쳤습니다.
- Apple 위젯에서 Todo 체크, 즉시 갱신, 라이트·다크 테마 대응을 개선했습니다.
- Google 로그인 사용자는 앱에서 내용을 확인한 뒤 버그를 제보할 수 있습니다.
  연락용 이메일과 공개 GitHub 이슈는 따로 나눴습니다.
- Daily 소개, 익명 분석 선택, Siri 설정, 알림·알람 권한, 계정 선택을 단계별
  온보딩으로 묶었습니다.
- 빠른 보기, 설정, 검색·필터, 일정 편집, 캘린더 가져오기, Siri 기록 화면을
  Apple 플랫폼에 맞는 공통 UI로 바꿨습니다.
- 계정 연결, 백업·복원, 로그아웃, 계정 삭제 버튼의 디자인과 상태 표시를
  통일했습니다. 개발 확인용 알림 테스트 기능만 뺐습니다.
- 캘린더 위아래 조작부의 외곽선을 정리했습니다. 오늘, 이동, 필터, 설정, 빠른
  보기, 달력, AI 아이콘은 알아보기 쉬운 모양으로 교체했습니다.
- macOS 월간 보기와 주간·일간 목록/스케줄에서 트랙패드 페이지 이동이 다시
  깨진 문제를 고쳤습니다.
- Apple 전용 Siri 기능을 뺀 공통 온보딩과 계정·설정 UI를 Android와 Windows에도
  적용했습니다. 새로 설치했을 때 익명 분석 선택 단계가 반복되던 문제도
  고쳤습니다.
- Android에서 고주사율 화면과 터치 입력, 삼성 생체 인증 반복 요청, 월간 이동 시
  월 표시와 인접한 달 날짜 표시를 보정했습니다.
- Android 월간·오늘 일정·D-day 홈 화면 위젯을 새 디자인으로 바꿨습니다.
  위젯에서 Todo 완료 상태를 바로 바꿀 수 있습니다.
- Windows 트레이에 미니 캘린더를 추가했습니다. 월간·오늘 일정·D-day를 보고
  Todo를 바꿀 수 있습니다.
- Windows 월간·주간·일간 보기에서 마우스 휠과 가로 휠 페이지 이동을
  보정했습니다. 주간·일간 스케줄의 세로 이동은 월간 보기와 같은 완화
  애니메이션을 씁니다.
- Windows에서 설정 저장이 UI isolate를 막아 애니메이션 프레임이 약 0.3~0.5초
  멈추던 문제를 고쳤습니다. 이제 바뀐 키만 차례로 저장하고, 눌림 모션이 끝난 뒤
  반영합니다. 빠르게 연속 입력하거나 동기화·복원과 겹쳐도 최신 설정을
  지킵니다.
- Windows 앱 이름과 아이콘을 DailyCalendar로 통일했습니다. 설치 프로그램은
  하나로 합쳤고, GitHub 최신 릴리스를 기준으로 자동 업데이트합니다.
- 익명 사용성 분석은 선택 사항이며 기본으로 꺼져 있습니다. 사용자가 동의한
  Release 빌드만 운영 집계 서버로 보냅니다. 일정 내용, 검색어, 계정, 광고
  식별자, 영구 기기 식별자는 분석에 넣지 않습니다.

## GitHub 배포 파일

GitHub Actions가 `v3.3.1` 릴리스에서 공개 검증용 파일을 만듭니다.

- `daily-ios-3.3.1-unsigned.ipa`
- `daily-macos-3.3.1-unsigned.dmg`
- `daily-android-3.3.1.apk`
- `daily-windows-3.3.1-setup.exe`
- `daily-windows-3.3.1.zip`

GitHub의 unsigned IPA와 DMG는 App Store 제출용이 아닙니다. Transporter로
제출할 서명 IPA/PKG는 로컬 `dist/transporter-upload/3.3.1`에서만 만듭니다.
