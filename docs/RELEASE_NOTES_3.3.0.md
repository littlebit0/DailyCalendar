# DailyCalendar 3.3.0 릴리스 노트

## 릴리스 정보

- 앱 표시 버전과 빌드: `3.3.0 (3.3.0)`
- Apple 앱 번들 ID: `com.littlebit0.daily`
- Apple 위젯 번들 ID: `com.littlebit0.daily.widgets`
- 이전 버전: `3.2.1`

## 바뀐 점

- 처음 실행할 때 Daily 소개, 익명 사용성 분석 선택, Siri 설정, 알림·알람 권한,
  계정 선택을 차례로 진행하는 단계형 온보딩을 넣었습니다.
  - 익명 분석은 기본으로 꺼져 있고, 사용자가 동의해야만 작동합니다.
  - 분석을 거절해도 앱을 그대로 쓸 수 있고, 같은 선택을 다시 강요하지 않습니다.
  - Apple 플랫폼에서는 검증된 `시그널` 단축어 추가 화면으로 바로 이동할 수 있습니다.
- 빠른 보기, 설정, 검색·필터, 일정 편집, 캘린더 가져오기, Siri 기록 화면을
  iOS와 macOS에 맞춘 공통 정보 구조와 라이트·다크 색상으로 다시 정리했습니다.
- 온보딩 권한 단계를 마친 뒤에도 계정 선택 버튼이 비활성화된 채 남던 문제를
  고쳤습니다.
- 설정의 Apple·Google 연결, 백업·복원, 로그아웃, 계정 삭제 버튼이 같은 상태·아이콘·높이
  규칙을 따르도록 맞췄습니다.
- 개발 확인용 `알림 테스트` 기능을 없앴습니다. 일정 알림, 아침 브리핑, D-day 알림은
  그대로 있습니다.
- 반복 일정의 한 발생분을 Todo 완료하면 다른 발생분까지 완료되던 문제를 고쳤습니다.
  - 이제 선택한 발생분만 별도 일정으로 분리합니다.
  - 반복 원본과 분리한 일정의 변경을 한 번에 원자 저장하고 v2 동기화 큐에 넣습니다.
- 주·월·일 캘린더의 동작과 배치 계산은 그대로 두고 상단·하단 조작부를 정리했습니다.
  - 연·연월 선택 버튼을 예전의 단순한 투명 디자인으로 되돌렸습니다.
  - 상단 메뉴와 iOS 하단 슬라이드에서 불필요한 외곽선을 없앴습니다.
  - 오늘, 이동, 필터, 설정, 빠른 보기, 달력, AI 아이콘을 알아보기 쉬운 모양으로
    바꿨습니다.
- 새로 만들거나 바꾼 화면의 문구를 한국어, 영어, 일본어, 중국어 번체로 번역했습니다.

## GitHub 배포 파일

GitHub Actions가 `v3.3.0` 릴리스에 공개 검증용 파일 두 개를 만듭니다.

- `daily-ios-3.3.0-unsigned.ipa`
- `daily-macos-3.3.0-unsigned.dmg`

GitHub에 올라간 unsigned IPA와 DMG로는 App Store에 제출할 수 없습니다. App Store
Transporter 제출용 서명 파일은 공개 릴리스에 넣지 않습니다.

## App Store 제출 파일

Transporter 제출용 서명 파일은 로컬 `dist/transporter-upload/3.3.0`에서만
만들고, Git 저장소와 GitHub Release에는 올리지 않습니다.

## 배포 후 확인할 것

- 새로 설치할 때와 기존 사용자가 업데이트할 때 온보딩·분석 동의 분기가 맞게 동작하는지
- Apple·Google·로컬 계정 진입과 설정의 계정 작업이 정상인지
- 실제 iPhone/iPad와 Mac에서 빠른 보기, 검색·필터, 일정 편집, 캘린더 버튼이 정상인지
- 반복 일정 한 발생분을 Todo 완료해도 다른 발생분이 바뀌지 않는지
- App Store Connect가 iOS와 macOS 빌드를 각각 올바른 플랫폼으로 처리하는지
