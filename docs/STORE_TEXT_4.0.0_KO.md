# 4.0.0 한국어 스토어 문구

## 이 버전에서 업그레이드 사항

• 지역 지도와 대학 로고로 학사정보를 더 쉽게 선택할 수 있습니다.
• 대학 학사일정 연동 범위를 확대하고 학교 시간표의 분류와 검색을 개선했습니다.
• LMS 로그인 정보를 기기별 보안 저장소에 저장하는 자동 로그인을 추가했습니다.
• LMS 퀴즈 완료 상태를 반영하고 직접 완료한 일정은 유지합니다.
• LMS 반복 조회와 시작 동기화 처리를 개선했습니다.
• 완료 취소선과 빠른 보기·시간표 전환, 대학 목록 스크롤을 개선했습니다.

학교 시간표 검색은 현재 지원하는 10개 대학에서 제공하며, 다른 대학의 학사일정과 직접 작성한 시간표는 유지됩니다. LMS 자동 로그인은 설정한 기기에만 적용되며, 학교 정책에 따라 다른 기기의 세션이 종료될 수 있습니다.

## 프로모션 텍스트

일상과 대학 생활을 한 캘린더에서 관리하세요. 지역별 대학 선택, 학사일정, 시간표와 지원 학교의 LMS 일정을 연결하고 여러 기기에서 이어서 확인할 수 있습니다.
