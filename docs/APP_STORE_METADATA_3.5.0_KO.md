# DailyCalendar 3.5.0 App Store Metadata (ko)

iOS/macOS 공통 등록 문구입니다. iPhone 전용 기능은 본문에 구분했습니다.
프로모션 텍스트는 170자 이하, 설명과 업데이트 내용은 각각 4,000자 이하입니다.
이 문서 작성은 App Store Connect에 저장하거나 심사를 제출했다는 뜻이 아닙니다.

## 프로모션 텍스트

일정과 할 일을 한곳에서 관리하세요. 더 자연스러운 일정 드래그, 보기 쉬운 완료 표시, 지역별 날씨와 상명대학교 학사 일정까지. 기기 간 변경 내용을 더 세밀하게 반영하는 동기화로 DailyCalendar가 한층 편리해졌습니다.

## 설명

하루의 일정부터 해야 할 일까지, DailyCalendar로 한곳에서 정리하세요.
계정 없이 시작하고, 필요할 때 Google 계정을 연결해 여러 기기에서 일정을 이어갈 수 있습니다.

[내 방식에 맞는 달력]
월간·주간·일간·연간 달력과 빠른 보기로 필요한 일정을 확인하세요. 주간·일간은 목록 또는 시간표 형태로 선택하고, 첫 화면과 주 시작 요일도 원하는 방식으로 설정할 수 있습니다.

[일정과 할 일을 함께]
일정을 완료로 체크하고 취소선으로 구분하세요. 반복 일정, 여러 날에 걸친 일정, 종일 일정과 D-day를 관리하고, 장소·링크·메모도 함께 기록할 수 있습니다. 드래그로 날짜와 순서를 바꾸고, 시간표에서는 30분 단위로 일정을 옮길 수 있습니다.

[분류와 색상으로 깔끔하게]
직접 고른 색상과 분류로 일정을 구분하세요. 분류 순서와 표시 여부, 일정 정렬, 제목 정렬, 글자 크기와 밝은·어두운 테마를 설정할 수 있습니다. 대한민국 공휴일과 음력 표시도 지원합니다.

[날씨와 학사 일정]
선택한 지역의 기상청 예보를 달력에서 확인하세요. 위치 권한 없이 지역을 직접 선택할 수도 있습니다. 상명대학교 학부 학사 일정을 미리 보고 필요한 항목만 가져오면, 대학 이름의 분류와 선택한 색상으로 정리됩니다.

[위젯, 알림과 Siri]
위젯으로 일정을 확인하고 오늘 일정의 완료 상태를 변경하세요. 일정 알림, 아침 브리핑과 D-day 알림을 지원합니다. 시그널 단축어를 설정하면 Siri를 통해 일정을 조회·추가·수정할 수 있으며, 실행 기록도 설정에서 확인할 수 있습니다.
iPhone에서는 지원되는 iOS 버전의 시스템 알람과 잠금화면 위젯, 월간 달력 배경화면용 이미지도 사용할 수 있습니다.

[필요할 때 연결하는 동기화]
Google Drive의 앱 전용 공간을 이용해 일정과 설정을 백업·복원합니다. 실제 변경 시각을 비교하고 설정을 항목별로 병합해 여러 기기의 변경 내용을 반영합니다. 일반 Google Drive 파일은 읽거나 수정하지 않습니다.

한국어·영어·일본어·중국어 번체를 지원하며, 시스템 언어를 따르거나 앱에서 직접 선택할 수 있습니다.

날씨는 기상청이 제공하는 대한민국 지역과 예보 기간에 한해 표시됩니다. Siri·위젯·시스템 알람은 기기와 OS 버전, 권한 및 단축어 설정에 따라 사용할 수 있는 범위가 다릅니다. iPhone 배경화면과 자동화는 사용자의 선택 및 설정이 필요합니다.

## 이 버전에서 업그레이드 사항

더 자연스러운 일정 이동과 세밀해진 동기화를 만나보세요.

- 일정의 실제 추가·수정·삭제 시각을 비교해 최신 변경을 반영하도록 동기화를 개선했습니다.
- 분류 이름·색상과 날짜별 일정 순서 등 설정을 항목별로 병합하고, 동시 변경과 재시도 처리를 개선했습니다.
- 앱 시작 시 필요한 동기화와 데이터 업데이트를 처리하고, 데이터 업데이트 실패 시 원본을 보존하도록 개선했습니다.
- 삭제한 일정 중 예정 날짜가 지난 항목의 본문을 정리하되, 삭제하지 않은 과거 일정은 유지합니다.
- 드래그 중 일정의 모양·제목·색상·정렬이 자연스럽게 이어지도록 개선했습니다. Mac에서는 달력과 사이드바 사이의 크기 전환도 다듬었습니다.
- 주간 시간표에서 여러 날에 걸친 종일 일정을 하나의 연속 막대로 표시합니다.
- 완료 취소선의 대비와 모바일 하루보기 팝업의 단계별 스크롤을 개선했습니다.
- 선택형 지역 날씨 예보와 상명대학교 학부 학사 일정 가져오기를 추가했습니다. 가져오기 화면에서 분류 색상도 지정할 수 있습니다.
- iPhone 잠금화면용 월간 달력 이미지와 단축어 설정 흐름을 추가했습니다.
- 새 기능 안내, 초기 분류 설정, 자주 사용하는 장소 관리와 일정 편집 화면의 키보드 동작을 개선했습니다.

동기화를 이용한다면 같은 Google 계정을 연결한 모든 기기를 3.5.0으로 업데이트해 주세요. 이전 버전과 새 버전의 동기화 데이터 처리 방식이 달라 구버전과의 혼용은 피해주세요.
