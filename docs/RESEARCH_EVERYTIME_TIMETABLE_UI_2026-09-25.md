# 에브리타임 시간표 UI 조사 — 2026-09-25

## 조사 결론과 범위

에브리타임의 시간표는 학기/시간표 이름을 중심으로 주간 수업을 보는 화면과,
기존 시간표를 계속 보면서 아래에서 강의를 탐색하고 추가하는 화면으로 나뉜다.
현재 Daily는 주간 격자의 일부 특징을 반영했지만 강의 탐색·추가 흐름은 다르다.
이번 작업은 조사다. 제품 코드나 설치된 앱은 수정하지 않았다.

아래에서 **관찰**은 공개 이미지·문서에서 직접 본 내용, **해석**은 그로부터
도출한 UX 판단이다. 공개 이미지의 학기 표기를 앱 출시/촬영일로 간주하지 않는다.
2026-09-25에 확인한 공개 자료와 최신 로그인 앱의 실제 동작은 구분한다.

## 기본 시간표 화면: 직접 관찰

Google Play 시간표 스크린샷은 위에서 아래로 다음 순서다.

1. 작은 강조색 학년도·학기.
2. 굵고 큰 시간표 이름. 예시는 `시간표 1`.
3. 오른쪽의 추가·설정·목록 모양 아이콘.
4. 화면 폭을 채우는 요일/시간 격자.
5. 표 아래 학점계산기 카드.
6. 친구 검색 영역과 앱 공통 하단 탐색 탭.

App Store 스크린샷은 같은 학기/제목 위계를 사용하지만 우측에 연필 아이콘 하나가
보인다. 반면 대학 안내의 iPhone 화면에는 추가/설정/목록이 보인다. 따라서
"iOS는 항상 연필 하나" 또는 "모든 플랫폼에 세 아이콘"이라고 확정할 수 없다.
플랫폼뿐 아니라 촬영 버전이나 화면 상태 차이도 가능한 설명이다.

격자의 관찰 특징:

- 상단은 월~금 요일, 왼쪽은 좁은 시각 열. 9, 10, 11, 12, 1, 2 순의 표기.
- 요일 아래 날짜 숫자나 주 이동 도구는 해당 기본표 예시에 없다.
- 옅은 회색 선이 열/행을 나누고, 비어 있는 시간은 같은 바탕색으로 남는다.
- 블록 높이는 수업 시간 길이를 나타낸다. 30분 위치에 시작하는 예시도 보인다.
- 같은 과목은 다른 요일에도 같은 색을 쓴다. 블록 사이 간격이 작아 시간 점유가
  하나의 면으로 읽힌다. 격자 바깥 테두리는 둥글지만 내부 블록은 직사각형이다.
- 블록은 왼쪽 위에 굵은 과목명, 그 아래 작은 강의실. 교수명·학점·상세 시각을
  매번 넣지 않는다. 긴 과목명은 여러 줄로 줄바꿈한다.
- 샘플은 색 면 위 밝은 글자를 사용한다. 정확한 RGB, 대비, 글자 크기, 다크모드
  규칙은 이미지로 확정하지 않는다.

**해석:** 화면의 정보 우선순위는 학기와 표의 이름, 수업 배치, 과목명과 강의실이다.
반복적인 설명문과 편집 도구를 표 주변에 많이 펼쳐 두는 구성은 아니다.

## 강의 검색/추가 화면: 직접 관찰

대학 배포 PDF 31–35쪽에서 확인한 흐름:

`시간표 탭 → 상단 추가 → 위쪽 시간표 + 아래쪽 강의 목록 → 필터/검색 → 강의 펼치기 → 시간표에 추가`

- 강의를 찾는 동안 위쪽에는 기존 수업의 배치가 계속 보인다.
- 상단에는 닫기와 `마법사`, `직접 추가` 버튼이 보인다. 마법사의 세부 동작은
  이 자료로 확인하지 않았다.
- 격자 아래에 `전공/영역`, 검색어 또는 교수명, `정렬`, `시간`의 작은 둥근
  필터가 가로로 이어진다. 선택된 조건은 강조색과 해제 표시를 사용한다.
- 전공/영역은 해당 대학 예시에서 캠퍼스 → 분류 → 학부/영역으로 들어가는 계층형
  선택이다. 현재 Daily의 한 단계 학과 드롭다운과 다르다.
- 결과 목록은 과목명/교수/요일·교시/강의실/학점/학수번호 등의 정보를 조밀하게
  보여 준다. 공식 홍보 이미지에는 별점, 담은 수, 정원도 있다.
- 선택된 강의는 목록 안에서 배경이 달라지고 `시간표에 추가`와 `강의평` 버튼이
  드러난다. 안내문은 추가 버튼이 시간표에 저장한다고 명시한다.
- `강의평`은 별도 강의 정보·평가 화면으로 연결된다. 일반 편집 폼을 필수로
  한 번 더 통과한다는 흐름은 이 안내에서 보이지 않는다.

PDF 35쪽에서 선택된 강의와 함께 격자에 회색 블록이 보인다. 앞선 페이지의
격자와 비교하면 **후보 강의 미리보기로 해석할 수 있다.** 다만 저장 전후를
직접 조작해 검증하지 않았으므로 정확한 표시 시점/애니메이션/충돌 상태는 미확인이다.

**해석:** 과목을 고르면서 기존 수업 사이에 들어가는지 판단할 수 있는 것이 핵심이다.
검색 화면과 시간표를 반복해서 왕복하는 비용을 줄인다.

## 수업 상세와 꾸미기: 공식 2022년 가이드에서 확인

[에브리타임 공식 블로그](https://blog.naver.com/everytimekr/222656444735)의 공개
모바일 페이지와 이미지를 확인했다. 게시일은 2022-02-24이므로 다음은 당시 UI다.

- 수업을 누르면 표를 배경으로 아래 상세 패널이 열린다. 과목·교수·여러 요일의
  시간·장소를 모아 보여 주고, 강의평·강의계획서·메모·할일·약칭·삭제로 이어진다.
- 약칭은 긴 과목명의 표시를 줄이는 별도 입력 기능이다. 초기화·취소·확인 동작이
  있으며, 공식 과목명과 표시 이름을 구분하는 설계로 읽힌다.
- 표의 설정 메뉴에는 이름/공개 범위/테마·스타일/위젯/이미지 저장/URL·카카오톡
  공유/삭제가 보인다. 이름 변경은 텍스트 입력 대화상자다.
- 테마 화면은 위쪽 시간표 미리보기와 가로 테마 썸네일을 함께 보여 준다.
  선택 테마를 테두리로 구분하고, 아래에는 글씨 크기·표시할 수업 정보·시작 시각이 있다.
  밝은 글자만 쓰는 규칙이 아니다. 파스텔 예시는 연한 면에 어두운 글자다.

이 자료는 수업 조회와 편집을 구분하는 UI의 실제 근거다. 복수 시간표·복제·대표
지정 규칙이나 현행 설정의 모든 항목까지 증명하지는 않는다.

## 최근 캘린더 확장

2025-12-11 공식 PM 인터뷰는 2025년 10월 캘린더를 도입했다고 설명한다.
학기 시간표 자동 연동, 개인 일정, 학교 학사일정을 함께 제공하고, 필요에 따라
시간표/학사일정 표시를 끌 수 있다. 글의 실제 이미지에는 하단 `시간표` 탭을
선택한 상태의 월간 달력이 보인다.

설정은 `캘린더 관리` 하단 시트로 나타나며 공휴일·학사일정·시간표에 각각 색상점과
표시/숨김 눈 아이콘이 있다. 상단의 전환 모양 아이콘이 어떤 탭 순서/제스처로
주간표와 연결되는지는 직접 확인하지 않았다.

이것은 주간 수업표와 별도의 날짜별 일정 기능이 있다는 근거다. Daily에서 기존에
정한 일반 달력/수업 표시 범위를 변경하라는 요구로 해석하지 않는다.

## 확인되지 않은 항목

현행 로그인 앱의 정확한 메뉴, 빈칸 탭/길게 누르기/드래그, 시트 높이 조절 제스처,
정렬/시간 필터의 전체 선택지, 시간표 생성·복제·대표 지정의 세부 규칙,
최신 테마/표시 범위 설정 전체, 강의 상세/편집의 최신 흐름, 다크모드 색상,
iPad 전용 레이아웃은 이번 공개 자료 조사만으로 확정하지 않는다.

Daily의 기본/주간 변경 토글, 빈칸 탭 즉시 직접 입력, 겹침 제외 체크박스는 현재
Daily에 추가한 설계다. 이를 그대로 에브리타임의 실제 UI라고 설명하지 않는다.
