# DailyCalendar 4.3.0

1차 지원 대학 72곳의 학교 시간표 검색을 열고, LMS 과제 마감 알림 설정을 추가한 업데이트입니다.

## 바뀐 점

- 1차 지원 대학 72곳 모두 학교 시간표 강좌 검색을 지원합니다.
  - 강좌는 확정(요일·시각 있음), 시간 미정(시각 없이 추가), 추가 불가로 나눠 보여 줍니다.
  - 시간 미정 강좌는 원문과 사유를 비고로 보여 줍니다.
  - 집중이수·특정 주차 강좌는 공식 시간표의 기간에만 들어갑니다.
- LMS 설정 화면에서 과제 마감 알림을 켤 수 있습니다.
  - 마감 몇 시간 전부터, 몇 시간 간격으로, 모두 몇 번 알릴지 고릅니다.
  - Daily에서 완료 처리한 과제는 알리지 않습니다. 이미 지난 알림 시각은 건너뜁니다.
  - 기본값은 꺼짐입니다.
- 자정을 넘기면 오늘 표시·D-day·현재 시각 선을 갱신합니다.
- 월간 달력과 주간 목록의 일정 시각에 12/24시간 설정을 적용합니다.
- 주간·일간 보기에서 고른 날짜의 달로 월간 보기를 엽니다. 월간 달 이동 때 고른 날짜를 기억합니다.
- 타임라인에서 일정을 끌 때 가장자리에서 자동으로 스크롤합니다. 이어 붙은 짧은 일정 블록이 겹치지 않습니다.
- 기기 글자 크기를 앱 글자 배율에 반영합니다(최대 1.3배). 강조색·주말 날짜색은 명암비 4.5:1을 맞춥니다.
- Android 위젯에서 누른 날짜·일정으로 앱이 이동합니다.
- Android 보안 저장소 키를 잃으면 잠금 화면에서 PIN을 다시 정할 수 있습니다.
- Google 종일 일정 알림을 Daily 종일 알림 시각 기준으로 바꿔 가져옵니다. 가져온 29~31일 매월·매년 반복은 그 날짜가 없는 달을 건너뜁니다.
- LMS 동기화 한 번을 5분 안에 끝내고, 남은 읽기는 다음 동기화에서 이어 읽습니다.
- 새 학년도 학사일정이 아직 게시되지 않았으면 이전 학년도 1~2월 일정을 유지합니다. 대체공휴일은 법령 시행일 이후에만 계산합니다.
- Siri·단축어 이름, macOS 권한 안내, Apple 위젯·알람 문구를 4개 언어로 제공합니다.
- iPhone Duo 안쪽 화면에서 배경화면 캔버스와 2열 설정 메뉴를 씁니다.

## 고친 문제

- iOS·macOS 보안 저장소 쓰기가 errSecParam(-50)으로 실패하던 문제
- 설정 저장 중 손상된 문서·중간 쓰기 실패로 변경이 사라지던 문제
- 일정의 동기화 시각 정보가 손상되면 조회와 DB 업그레이드가 멈추던 문제
- 저장된 학교 정보를 읽지 못하면 앱 시작이 멈추던 문제
- 앱 복귀 후 시작 동기화 자동 재시도가 다시 예약되지 않던 문제
- Android 보안 저장소의 예전 암호화 자료 이전이 실패하면 원본이 지워질 수 있던 문제

## 동기화·저장 형식 변경

Drive v2 파일 형식과 로컬 DB 스키마(15)는 4.2.0과 같습니다. 설정 파일에 LMS 과제 마감 알림 값(`lmsDueReminder`)이 추가됐습니다. 4.2.0 이하 기기에서 설정을 바꾸면 이 값이 기본값(꺼짐)으로 돌아갈 수 있으니, 같은 계정의 기기를 4.3.0으로 맞추세요.

## 알려진 제한

- Mac App Store용 4.3.0은 4.2.0과 마찬가지로 Apple Silicon(M 시리즈) Mac에서만 실행됩니다.
- 영남대학교, 경기대학교 서울캠퍼스, 건양대학교는 공개된 자료 일부로 시간표를 열어 강좌 수가 적거나 시간 미정 강좌가 많습니다.
- 2차 이후 대학의 학교 시간표는 아직 지원하지 않습니다.
- LMS 과제 마감 알림의 실제 알림 발송은 LMS 계정을 연결한 기기에서 확인하지 못했습니다.

## 검증

- main `2df8c926d`의 CI(Platform Builds)에서 Dart 분석·전체 테스트, 시간표 테스트 3개, Apple LMS 세션 테스트, Android·Windows Debug 빌드가 통과했습니다.
- macOS와 iOS 시뮬레이터 테스트 앱에서 LMS 과제 마감 알림 설정 화면, 값 유지, 영어 표시를 확인했습니다. 시간표는 대표 강좌를 화면에서, 나머지 사례는 앱에 들어 있는 시간표 자료로 확인했습니다.
- 4.3.0 버전 올림 커밋 `2cd0c6d04`로 Android `.aab`, iOS App Store `.ipa`, macOS App Store `.pkg`를 만들었습니다.
  - 세 파일 모두 버전 4.3.0(Android versionCode 430)을 확인했습니다.
  - 서명 인증서·팀·번들 ID는 4.2.0과 같습니다. Mac 바이너리는 arm64 단일입니다.
  - 이 파일들을 실제 기기에 설치해 쓰지는 않았습니다.
