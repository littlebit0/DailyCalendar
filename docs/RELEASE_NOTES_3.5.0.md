# DailyCalendar 3.5.0

## 주요 변경

- 일정 추가·수정·삭제의 실제 변경 시각을 UTC로 비교해 최신 변경을 반영합니다.
  업로드 시각이나 기기의 동기화 대기 상태 때문에 오래된 내용이 우선하던 흐름을 개선했습니다.
- 설정을 항목별로 병합합니다. 서로 다른 기기에서 변경한 분류 이름·색상과
  날짜별 일정 순서가 불필요하게 함께 덮어써지지 않도록 했습니다.
- 동시 업로드 충돌을 감지해 다시 비교하고, 부분 실패·미완료 상태를 성공으로
  표시하지 않습니다. 복원 전에 백업을 강제하지 않으며 자동 로그인 창도 띄우지 않습니다.
- 사용자가 삭제했고 마지막 예정 날짜까지 지난 일정의 본문을 정리합니다.
  삭제하지 않은 과거 일정은 보존하며, 삭제 일정의 재등장을 막는 최소 기록은 유지합니다.
- 앱 시작 시 필요한 동기화·DB 업데이트를 로딩 화면에서 처리하고,
  DB 마이그레이션에 안전 스냅샷과 실패 시 원본 보존 절차를 적용했습니다.
- 월·주·일간 일정 드래그의 제목·색상·정렬·모양 연속성을 개선했습니다.
  macOS 달력과 사이드바 사이에서는 대상 화면에 맞는 크기 전환을 유지합니다.
- 주간 스케줄의 여러 날에 걸친 종일 일정을 하나의 연속 막대로 표시합니다.
- 완료 취소선은 분류 색상과 밝은/어두운 테마를 함께 고려해 가독성을 높였습니다.
- 모바일 하루보기 팝업의 단계별 스크롤 동작을 조정했습니다.
- 선택형 날씨 예보와 지역 설정을 추가했습니다. 기상청이 제공하는 범위의
  예보만 표시하며, 위치 사용은 선택 사항입니다.
- 상명대학교 학부 학사 일정 미리보기·선택 가져오기·갱신을 추가했습니다.
  대학 이름의 분류가 생성되며, 가져오기 화면에서 분류 색상도 지정할 수 있습니다.
- iOS 잠금화면 월간 달력 이미지와 단축어 설정 흐름을 추가했습니다.
  배경화면 선택·자동화 설정에는 사용자의 설정과 권한 승인이 필요합니다.
- 새 기능 안내, 초기 분류 설정, 자주 사용하는 장소 추천·관리 및
  일정 편집 화면의 불필요한 키보드 자동 표시를 개선했습니다.

## 업데이트 전 확인

**같은 Google Drive 계정을 사용하는 모든 기기를 3.5.0으로 업데이트해 주세요.**
이번 버전은 DB 스키마 8, 설정별 변경 기록과 압축된 삭제 기록을 사용합니다.
구버전 앱은 새 충돌 규칙을 따르지 못하므로 같은 계정에서 혼용하지 마세요.
GitHub 파일 공개는 App Store 승인·출시 완료를 의미하지 않습니다.

시간대 차이는 UTC 비교로 처리하지만, 기기의 실제 시계가 잘못된 경우까지
자동 교정하지는 않습니다. 기존 설정에 없던 과거 변경 시각을 새로 만들어
추정하지 않습니다. 삭제 본문 정리는 현재 데이터에 적용하며 기존 안전 스냅샷과
Drive의 과거 리비전까지 모두 지운다는 의미는 아닙니다.

## 배포 파일

- iOS: `daily-ios-3.5.0-unsigned.ipa` (공개 검증용, 설치하려면 별도 서명 필요)
- macOS: `daily-macos-3.5.0-unsigned.dmg` (공개 검증용, 미공증)
- Android: `daily-android-3.5.0.apk` (버전 코드 350, 기존 3.4.0 배포 서명 유지)
- Windows: `daily-windows-3.5.0-setup.exe`, `daily-windows-3.5.0.zip`
- Linux: `daily-linux-3.5.0-1-amd64.deb`, `daily-linux-3.5.0-1-arm64.deb`

Apple 공개 파일은 Transporter 제출용이 아닙니다. Android 3.3.1 이전 서명키와는
호환되지 않으므로, 이전 버전 삭제 전 백업과 복원 가능 여부를 확인하세요.
