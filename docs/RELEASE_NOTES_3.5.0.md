# DailyCalendar 3.5.0

## 바뀐 점

- 일정 추가·수정·삭제가 실제로 일어난 시각을 UTC로 비교해 가장 최근 변경을 반영합니다.
  이전에는 업로드 시각이나 기기의 동기화 대기 상태 때문에 오래된 내용이 이기는 경우가 있었습니다.
- 설정을 항목별로 병합합니다. 한 기기에서 분류 이름·색상을 바꾸고 다른 기기에서
  날짜별 일정 순서를 바꿔도 서로의 변경을 덮어쓰지 않습니다.
- 동시 업로드 충돌을 감지하면 다시 비교합니다. 일부만 실패했거나 끝나지 않은 작업은
  성공으로 표시하지 않습니다. 복원 전에 백업을 강제하지 않고, 로그인 창을 자동으로 띄우지도 않습니다.
- 사용자가 삭제했고 마지막 예정 날짜도 지난 일정은 본문을 정리합니다.
  삭제하지 않은 과거 일정은 그대로 두고, 삭제한 일정이 다시 나타나지 않도록 최소 기록은 남깁니다.
- 앱을 시작할 때 필요한 동기화와 DB 업데이트를 로딩 화면에서 처리합니다.
  DB 마이그레이션은 먼저 안전 스냅샷을 만들고, 실패하면 원본을 보존합니다.
- 월간·주간·일간 화면에서 일정을 끌 때 제목·색상·정렬·모양이 끊기지 않도록 다듬었습니다.
  macOS 달력과 사이드바 사이를 오갈 때는 놓을 화면에 맞춰 크기를 바꿉니다.
- 주간 스케줄에서 여러 날에 걸친 종일 일정을 이어진 막대 하나로 표시합니다.
- 완료 취소선 색을 분류 색상과 밝은/어두운 테마에 맞춰 정해 더 잘 보이게 했습니다.
- 모바일 하루보기 팝업의 단계별 스크롤 동작을 조정했습니다.
- 원할 때 켜는 날씨 예보와 지역 설정을 추가했습니다. 기상청이 제공하는 범위의
  예보만 표시하며, 위치 사용은 선택 사항입니다.
- 상명대학교 학부 학사 일정을 미리 보고, 골라서 가져오고, 갱신할 수 있습니다.
  가져오면 대학 이름으로 분류가 생기고, 가져오기 화면에서 그 분류의 색상도 정할 수 있습니다.
- iOS 잠금화면에 쓸 월간 달력 이미지와 단축어 설정 흐름을 추가했습니다.
  배경화면 선택과 자동화 설정은 사용자가 직접 설정하고 권한을 승인해야 합니다.
- 새 기능 안내, 초기 분류 설정, 자주 쓰는 장소 추천·관리를 개선했습니다.
  일정 편집 화면에서 키보드가 불필요하게 자동으로 뜨던 문제도 고쳤습니다.

## 업데이트 전에 확인할 것

같은 Google Drive 계정을 쓰는 모든 기기를 3.5.0으로 업데이트해 주세요.
이번 버전은 DB 스키마 8과 설정별 변경 기록, 압축된 삭제 기록을 사용합니다.
구버전 앱은 새 충돌 규칙을 따르지 못하므로 같은 계정에서 섞어 쓰지 마세요.
GitHub에 파일을 공개했다고 App Store 승인이나 출시가 끝난 것은 아닙니다.

시간대 차이는 UTC 비교로 처리합니다. 기기 시계 자체가 틀린 경우는 자동으로 바로잡지 않습니다.
기존 설정에 없던 과거 변경 시각은 추정해서 만들지 않습니다. 삭제 본문 정리는 현재 데이터에만
적용하며, 기존 안전 스냅샷과 Drive의 과거 리비전까지 모두 지우지는 않습니다.

## 배포 파일

- iOS: `daily-ios-3.5.0-unsigned.ipa` (공개 검증용, 설치하려면 별도 서명 필요)
- macOS: `daily-macos-3.5.0-unsigned.dmg` (공개 검증용, 미공증)
- Android: `daily-android-3.5.0.apk` (버전 코드 350, 기존 3.4.0 배포 서명 유지)
- Windows: `daily-windows-3.5.0-setup.exe`, `daily-windows-3.5.0.zip`
- Linux: `daily-linux-3.5.0-1-amd64.deb`, `daily-linux-3.5.0-1-arm64.deb`

Apple 공개 파일은 Transporter 제출용이 아닙니다. Android 앱은 3.3.1 이전 서명키와
호환되지 않습니다. 이전 버전을 삭제하기 전에 백업하고 복원할 수 있는지 확인하세요.

## 확인한 범위

- 공유 Flutter 코드의 정적 분석과 자동화 테스트 548개를 통과했습니다. 기존 제외 항목은 1개입니다.
- iOS·macOS·Android 테스트 앱을 3.5.0으로 업데이트하고 DB와 설정 데이터가 보존되는지 확인했습니다.
  앱은 자동 실행하지 않았습니다.
- iOS·macOS·Android·Windows와 Linux amd64/arm64 배포 빌드가 모두 통과했습니다.
  [배포 빌드 결과](https://github.com/littlebit0/DailyCalendar/actions/runs/35096496706)
- 공개 설치 파일 7개의 SHA-256과 내부 버전을 확인했습니다.
  Android APK는 기존 배포 인증서와 일치하고 서명 검증을 통과했습니다.
- 서명된 Linux APT 채널에 3.5.0-1을 올리고 두 아키텍처의 공개 다운로드를 확인했습니다.
  [자동 업데이트 채널 검증](https://github.com/littlebit0/DailyCalendar/actions/runs/35097289398)
- 실제 계정에서의 동시 동기화, 실기기의 로그인·권한·알람·위젯, Windows/Linux 데스크톱
  실사용 검증은 자동 테스트·빌드 통과와 별개입니다.
