# DailyCalendar 4.1.0

## 같은 계정의 모든 기기를 업데이트해 주세요

이 버전부터 요일·시각이 정해지지 않은 학교 강좌(원격·시간 미정 강좌)를 시간표에 담을 수 있습니다. 시간 미정 강좌를 쓰려면 같은 Google 계정으로 동기화하는 모든 기기를 4.1.0 이상으로 업데이트해야 합니다.

4.0.0 이하 버전은 시간 미정 강좌가 들어 있는 시간표를 읽지 못합니다. 이 버전에서 시간 미정 강좌를 하나라도 동기화하면 같은 계정의 구버전 기기에서는 다음과 같이 됩니다.

- 시간표 복원이 중단되고 "Google Drive 시간표 데이터가 손상되었거나 지원하지 않는 형식입니다. 기존 데이터는 보존됩니다." 오류가 표시됩니다. 실제로 데이터가 손상된 것은 아닙니다.
- 같은 복원 과정의 일정·설정 복원도 함께 중단됩니다.
- 기기에 있는 기존 일정·설정·시간표는 지워지지 않고, Google Drive의 원본도 덮어쓰지 않습니다. 구버전 기기를 업데이트하면 다시 동기화됩니다.

Windows 앱은 릴리스 빌드에서 최신 버전을 확인해 자동으로 업데이트합니다. Android, macOS, iPhone·iPad는 앱 안에서 업데이트를 강제하지 않으므로 각 기기에서 직접 업데이트해 주세요.

## 배포 구분

Drive v2 시간표 문서 형식과 `schemaVersion`은 바꾸지 않았습니다. 시간 미정 강좌는 기존 형식에서 `meetings`가 빈 강좌로 저장됩니다. 이 변경이 구버전 기기의 동기화에 영향을 주므로 Windows·Android 산출물과 Mac·iPhone 산출물을 함께 게시합니다.

구버전과 신버전 기기를 함께 쓸 때의 동작은 v4.0.0 코드를 정적으로 확인한 결과입니다. 실제 Google Drive와 기기를 함께 쓰는 확인은 하지 않았습니다.
