# DailyCalendar 4.1.0

## 주요 변경

- 잊모기 탭을 추가했습니다. 기한 없는 할 일을 빠르게 적고, 미완료 개수를 배지로 확인하고, 일정으로 바꿀 수 있습니다.
- 일정 템플릿을 저장해 두고 일정 추가 화면에서 한 번에 등록할 수 있습니다. 템플릿에는 알람 시각(N분 전·지정 시각)도 함께 저장합니다.
- 일정의 시스템 알람 시각을 정시, N분 전, 날짜와 시각 지정 중에서 고를 수 있습니다.
- 자정을 넘는 일정을 다음 날에도 표시할지 정할 수 있습니다.
- 하루 일정 전체보기에서 좌우로 넘기면 이전·다음 날짜로 이동합니다. 시트는 아래로 한 번 끌어 닫을 수 있습니다.
- 시간표에서 특정 날짜만 바꾼 강의 방식(영상 강의·휴강 등)을 월·주·일간 캘린더에 "강의명 + 방식"으로 표시합니다.
- 요일·시각이 없는 강좌는 시간표 아래 "원격·시간 미정 강좌"에 표시합니다(아래 업데이트 안내 참고).
- 시간표 강좌 검색의 단과대·학과 선택을 하나로 합쳤습니다. 여러 학교 시간표의 교시 구간에 쉬는 시간을 포함하고, 같은 강의실에서 이어지는 수업은 한 블록으로 표시합니다.
- 학사일정 기본 틀을 새로 만들고, 71개 대학의 학사일정 연동을 1차 지원으로 추가했습니다. 학교가 날짜나 제목을 정정한 학사일정도 기존 일정에 연결합니다.
- LMS 로그인은 ID로 입력하도록 바꾸고, Apple 암호 자동완성, 저장한 계정으로 다시 로그인, 비밀번호 표시·숨김을 추가했습니다. 자동 재로그인에 실패하면 다시 시도하고, 지난 일정은 마감 후 한 번만 최종 동기화합니다.
- 앱에 오류가 나면 개인정보를 가린 오류 보고를 자동으로 보냅니다. 기본으로 켜져 있고 설정에서 끌 수 있습니다. 수동 버그 제보도 같은 방식으로 서버에 보관하도록 바꿨습니다.
- 일정·알림 정확도 문제를 고쳤습니다. 서머타임 경계에서 종일 일정·날짜 필터·자연어 날짜가 하루 밀리던 문제, 반복 일정 알림과 종료일 회차가 빠지던 문제, 외부 캘린더 반복 규칙을 보존하지 못하던 문제 등이 포함됩니다.
- Android에서 검색/필터 시트를 닫을 때 앱이 오류 화면으로 멈추던 문제를 고쳤습니다. Google을 다시 연결한 직후 동기화에 실패하면 계정 설정 표시가 갱신되지 않던 문제도 고쳤습니다.
- Windows·Linux·Android·Apple에서 WebView, 알림, 위치 권한, 보안 저장소, 위젯·Siri와 관련된 안정성 문제를 여러 건 고쳤습니다.

## 같은 계정의 모든 기기를 업데이트해 주세요

이 버전부터 요일·시각이 정해지지 않은 학교 강좌(원격·시간 미정 강좌)를 시간표에 담을 수 있습니다. 시간 미정 강좌를 쓰려면 같은 Google 계정으로 동기화하는 모든 기기를 4.1.0 이상으로 업데이트해야 합니다.

4.0.0 이하 버전은 시간 미정 강좌가 들어 있는 시간표를 읽지 못합니다. 이 버전에서 시간 미정 강좌를 하나라도 동기화하면, 같은 계정의 구버전 기기에서는 다음 일이 생깁니다.

- 시간표 복원이 멈추고 "Google Drive 시간표 데이터가 손상되었거나 지원하지 않는 형식입니다. 기존 데이터는 보존됩니다." 오류를 표시합니다. 데이터가 실제로 손상되지는 않았습니다.
- 같은 복원 과정에 있는 일정·설정 복원도 함께 멈춥니다.
- 기기에 있는 기존 일정·설정·시간표는 지우지 않고, Google Drive의 원본도 덮어쓰지 않습니다. 구버전 기기를 업데이트하면 다시 동기화합니다.

Windows 앱은 릴리스 빌드에서 최신 버전을 확인해 자동으로 업데이트합니다. Android, macOS, iPhone·iPad는 앱 안에서 업데이트를 강제하지 않으니 각 기기에서 직접 업데이트해 주세요.

## 배포 구분

Drive v2 시간표 문서 형식과 `schemaVersion`은 바꾸지 않았습니다. 시간 미정 강좌는 기존 형식 그대로 `meetings`가 빈 강좌로 저장합니다. 이 변경은 구버전 기기의 동기화에 영향을 주므로 Windows·Android 산출물과 Mac·iPhone 산출물을 함께 게시합니다.

구버전과 신버전 기기를 함께 쓸 때의 동작은 v4.0.0 코드를 정적으로 확인한 결과입니다. 실제 Google Drive와 기기를 함께 써서 확인하지는 않았습니다.

## 동기화·저장 형식 변경

- 로컬 DB 스키마가 9에서 12로 올라갑니다. 앱을 처음 실행할 때 기존 데이터를 옮기고, 옮기기 전 사본을 기기에 남깁니다.
- Google Drive v2에 일정 템플릿(`daily-sync-v2-templates.json`)과 잊모기(`daily-sync-v2-imogi.json`) 파일이 새로 생깁니다. 4.0.0 이하 버전은 이 파일을 읽지 않으므로 구버전 기기에서는 템플릿과 잊모기가 보이지 않습니다. 일정·설정·시간표 파일 형식은 바꾸지 않았습니다.

## 알려진 제한

- 자동 오류 보고와 수동 버그 제보를 받는 서버 수신기는 이 릴리스와 따로 배포합니다. 수신기를 준비하기 전에는 보고 전송이 실패할 수 있습니다.
- Mac App Store용 4.1.0은 Apple Silicon(M 시리즈) Mac 전용입니다. 현재 빌드 도구(Xcode 27과 Flutter 3.44.0)의 호환 문제로 Intel·Apple Silicon 공용 빌드를 만들지 못했습니다. Intel Mac에서는 App Store 4.1.0을 설치하거나 업데이트할 수 없습니다. GitHub 릴리스의 macOS DMG는 GitHub Actions 빌드 환경에서 따로 만듭니다.
- 학사일정 1차 지원 학교와 학교 시간표 자료는 학교 공개 자료를 기준으로 연동했습니다. 실제 계정으로 화면을 확인한 학교는 일부입니다.

## 검증

- main `CI(Platform Builds)`에서 전체 Dart 분석·테스트, Android·Windows Debug 빌드, Apple LMS 세션 테스트를 통과했습니다.
- macOS·iPhone 시뮬레이터·Android 에뮬레이터의 테스트 앱에서 4.0.0 이후 변경 가운데 화면에서 확인할 수 있는 기능을 직접 조작해 확인했습니다(OS별 16~28개 PR). 학교별 연동, 내부 로직, 로그인·전송이 필요한 기능, 위젯·Siri·실기기 동작은 대부분 확인하지 못했습니다.
- 이 테스트에서 찾은 문제 4건(#775~#778)은 고쳐서 이 버전에 넣었고, Android 테스트 앱에서 해결을 확인했습니다.
