# DailyCalendar 3.2.0 릴리스 노트

## 버전 정보

- 앱 표시 버전과 빌드: `3.2.0 (3.2.0)`
- Apple 앱 번들 ID: `com.littlebit0.daily`
- Apple 위젯 번들 ID: `com.littlebit0.daily.widgets`
- 이전 버전: `3.1.0`

## 바뀐 점

- 모든 사용자 일정에 Todo 완료 상태를 추가했습니다. 빠른 보기, 월·주·일
  캘린더, 일정 상세, Apple 위젯에서 완료 여부를 보고 바꿀 수 있습니다.
- 기존 사용자 데이터는 원격 복원, 로컬 안전 스냅샷 저장, 검증, 원자적 교체
  순서로 마이그레이션합니다. 중간에 실패하면 원본 데이터를 그대로 둡니다.
- 월간·주간·일간 일정과 macOS 하루 패널에서 일정을 길게 눌러 다른 날짜로
  옮기거나 날짜 안의 순서를 직접 정할 수 있습니다.
- 분류 순서와 `분류 우선 / 시간 우선` 일정 정렬을 추가했습니다. 공휴일 분류
  색상과 날짜 배경 선택도 지원합니다.
- 반복 일정이 종료일 당일에 빠지던 문제를 날짜 포함 규칙을 고쳐 해결했습니다.
- 주간·일간 스케줄 보기에서 주말 색상, 종일 일정 높이, 기간 표기, macOS 마우스
  이동 동작을 개선했습니다.
- 설정 항목마다 뜻에 맞는 아이콘을 붙였습니다. 일정 제목 정렬, 분석 동의,
  데이터 삭제 같은 개인 설정도 보강했습니다.
- 수동 Google Drive 복원은 복원 전에 백업을 실행하지 않습니다. 원격 파일을
  모두 검증한 뒤 하나의 트랜잭션으로 적용해 데이터를 더 안전하게 지킵니다.
- Apple 위젯에서 Todo를 체크하면 실제 일정 데이터에 바로 동기화합니다. 모든
  위젯이 앱의 `자동`, `화이트`, `다크` 테마를 똑같이 따르도록 고쳤습니다.
- macOS 테스트 위젯 확장이 중복 등록되던 문제와 테마를 빠르게 바꿀 때 생기던
  갱신 경합을 정리했습니다. 이제 일부 위젯만 이전 테마로 남지 않습니다.
- Siri 시그널 단축어 설치 안내와 실행 기록을 개선했습니다. 앱 아이콘과 시작
  화면 이미지는 최신 DailyCalendar 디자인으로 바꿨습니다.
- 익명 사용성 분석은 기본으로 꺼져 있습니다. 사용자가 직접 허용해도 일정 내용,
  검색어, 계정 정보, 광고 식별자는 수집하지 않습니다.

## 검증

- `./tool/flutter.sh analyze --no-pub`
- `./tool/flutter.sh test --no-pub` 전체 242개
- `./tool/flutter.sh build macos --debug --no-pub`
- `./tool/flutter.sh build ios --simulator --debug --no-pub`
- macOS에서 오늘 일정 위젯과 주간 위젯의 화이트·다크·자동 테마를 실제 GUI로 확인
- iOS/macOS 앱과 위젯의 버전과 빌드가 `3.2.0 (3.2.0)`인지 확인

## GitHub 배포 파일

GitHub Actions가 `v3.2.0` 릴리스에 공개 검증용 파일 두 개를 만듭니다.

- `daily-ios-3.2.0-unsigned.ipa`
- `daily-macos-3.2.0-unsigned.dmg`

GitHub에 올린 unsigned IPA와 DMG로는 App Store에 제출할 수 없습니다. App Store
Transporter로 제출할 서명 파일은 공개 릴리스에 넣지 않습니다.

## 아직 확인하지 않은 것

- App Store Connect 제출 전 iOS/macOS Release 아카이브와 서명 검증
- Android 실제 기기와 Windows 실제 OS에서 3.2.0 회귀 검증
