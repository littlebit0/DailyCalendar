# Daily 3.6.0 스토어 문구

## 이번 버전의 개선 사항

학사일정과 시간표, 학교 과제를 Daily에서 함께 관리하세요.

• 학사 관리 메뉴 추가: 학사 정보, 학교 LMS, 학사일정, 시간표 설정을 한곳에 모았습니다.
• 시간표 지원: 상명대학교·단국대학교·전남대학교의 강의를 검색하고 시간표에 추가할 수 있습니다. 이수구분, 분반, 강의실과 비고도 확인하세요.
• 학기별 시간표: 연도·학기 목록으로 이동하고, 해당 학기 기간에만 주·일간 달력에 수업을 표시합니다.
• 학교 LMS 연결: 상명대학교 과제·퀴즈를 자동으로 가져옵니다. 개인 분류를 선택하면 기존·신규 LMS 일정에 적용되며, 사용 중 주기적으로 변경 사항을 확인합니다.
• Google Drive 동기화: 시간표와 학사 설정을 기기 간에 이어서 사용하세요.
• 사용성 개선: 달력·시간표 전환, macOS 상단 메뉴, 어두운 테마의 팝업 경계를 다듬었습니다.
• 안정성 개선: 시작 동기화 지연과 불필요한 전체 일정 재처리를 수정했습니다.

LMS는 현재 상명대학교 과제·퀴즈를 지원하며, 학교 인증 만료 시 다시 로그인해야 합니다.

## 프로모션 텍스트

일정부터 시간표, 학교 과제까지 Daily에서 함께 관리하세요. 상명대·단국대·전남대 시간표와 학사일정을 지원하고, 상명대 LMS 과제·퀴즈는 원하는 분류로 자동 동기화합니다.

## 입력 기준

프로모션 텍스트는 170자 이내로 작성했습니다. Apple 안내: https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information
