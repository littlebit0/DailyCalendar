# 대학 시간표 (#74 / #75)

## 사용 범위

Daily는 전국 대학생이 자신의 학교를 등록할 수 있는 캘린더입니다. Google 로그인 후
학사 정보는 **4년제 대학만** 운영하며 학교 이름이나 초성으로 검색합니다.
학제 구분 탭은 표시하지 않습니다. 선택 가능한 학교는 183개이며, 기존 프로필
호환성을 위해 원본 429개 대학·캠퍼스 식별자는 보존합니다. 전문대·사이버대·군사·
신학 전문대학과 LH토지주택대학교는 새 선택 목록에서 제외합니다.
자료 범위·기준일·제외 기준은 [전국 대학 목록 자료](UNIVERSITY_DIRECTORY_SOURCES.md)를 확인하세요.

통합 캠퍼스는 한 학교로 등록하며 캠퍼스 선택을 요구하지 않습니다. 학교 이름 아래
공식 캠퍼스 명칭을 보조 표시합니다. 고려대·연세대·건국대·동국대·한양대처럼 별도
행정의 분교가 있는 다섯 대학은 캠퍼스를 따로 선택합니다. 학교 선택 화면 아래의
선택 결과에는 테두리를 표시합니다. 이전 캠퍼스별 식별자로 저장된 프로필도 복원합니다.
학과나 입학년도를 수집하거나 저장하는 기능은 포함하지 않습니다. 선택한 학사 정보는
연결한 Google 계정의 Drive 설정으로 동기화되며 다른 기기에서도 같은 학교를 사용합니다.

**학사일정 추가와 시간표는 상명대학교(서울·천안), 단국대학교(죽전·천안),
전남대학교(광주·여수)를 지원합니다.**
다른 대학도 자신의 학교를 선택하고 학사 정보를 저장할 수 있지만, 해당 학교의
연동 기능이 준비되기 전에는 상명대 자료를 대신 제공하지 않습니다. 학교 이름의
유사성이 아닌 저장된 대학·캠퍼스 식별자로 지원 여부와 자료를 결정합니다.
일반 캘린더 기능은 특정 대학의 재학 여부와 관계없이 사용할 수 있습니다.

지원 학교에서는 시간표 탭에서 학기를 선택하고 수업을 직접 추가하거나 학교 강의
목록에서 검색해 추가합니다. 과목 하나에 여러 요일/시간과 각 시간의 강의실을 저장할 수
있습니다. 교수명·색상·메모·기본 강의 방식은 수정 가능합니다.

시간표는 연결한 Google 계정의 Drive AppData로 저장하고 같은 계정을 사용하는
다른 기기와 동기화합니다. 기기 저장소는
오프라인 편집을 위한 캐시이며, 연결이 복구되면 대기 중인 변경사항을 자동으로
동기화합니다. 별도의 내보내기나 수동 파일 복사가 필요하지 않습니다.
기존 일반 일정의 저장소·DB 스키마 8·이벤트/설정 동기화 문서는 유지하고,
시간표에는 별도 AppData 문서 `daily-sync-v2-timetable.json`을 사용합니다.
시간표 탭에는 선택한 학기의 기본 시간표를 표시합니다. 주·일간 스케줄은 보고 있는
날짜에 해당하는 모든 학기의 수업을 **학기 시작일~종료일 안에서만** 표시합니다.
시간표 탭에서 다른 학기를 열어도 캘린더 내용은 바뀌지 않습니다. 기간이 없는 학기는
자료를 보존하되 기간을 설정하기 전까지 날짜별 스케줄에 넣지 않습니다.

등록한 학교의 공식 2026 학사일정으로 확인한 네 학기를 초기 기간으로 제공합니다.
이미 저장된 학기 기간과 사용자가 수정한 기간은 학교를 바꾸어도 보존합니다.
세 학교의 2학기는 9월 1일~12월 21일이며 보강·기말고사 기간을 포함합니다.
다른 학기는 시작일과 종료일을 직접
지정해야 합니다. 공식 근거와 다른 학기 기간은
[학기 기간 자료](TIMETABLE_PERIOD_SOURCES.md)에 기록합니다.
휴일이나 개별 휴강을 일괄 추정하지 않으며 기존 날짜별 회차 예외를 사용합니다.

수업이 표시되는 곳은 시간표 탭과 주/일간의 **스케줄 레이아웃**뿐입니다.
일반 월간·주간·하루 목록·검색·위젯에는 시간표 수업을 넣지 않습니다.
일반 일정 저장소로 수업을 삽입하지 않습니다.

## 시간표 화면

기본 화면은 학기 단위의 요일·시간 격자입니다. 월~금이 화면 폭에 맞고, 토·일
수업이 있으면 해당 요일까지 표시합니다. 기본 표시 시간은 09~18시이며 이보다
이르거나 늦은 수업은 자동으로 범위를 넓힙니다. 빈 시간 칸을 누르면 그 요일과
시간을 채운 전체 화면 팝업이 열리며, 저장하기 전에는 수업을 만들지 않습니다.
상단의 학기를 누르면 **25년도 1학기, 25년도 여름계절학기, 25년도 2학기,
25년도 겨울계절학기, 26년도 1학기…**처럼 연도와 학기가 결합된 목록을 엽니다.
연도를 텍스트로 입력하거나 연도와 학기를 따로 조합하지 않습니다.

저장된 학기는 이름·수업 수·기간과 현재 선택을 함께 표시하며 한 번 눌러 이동합니다.
아직 저장하지 않은 학기를 누르면 선택한 학기가 채워진 이름·기간 확인 양식을 엽니다.
공식 기간이 있는 학기는 그 값을 제안하고, 없는 학기는 시작일·종료일을 지정합니다.
취소하면 자료를 만들지 않으며, 생성한 빈 시간표도 목록과 Drive에 보존됩니다.
현재 보고 있는 학기는 기기별로 기억하여 다른 기기의 선택이나 동기화가 화면을
이동시키지 않습니다.

상단에는 시간표 이름, 강의 검색·직접 추가·관리 메뉴와 편집 가능한 학기 기간을
표시합니다. 기간이 없는 경우 설정 안내를 제공합니다. 관리 메뉴에서 기간과 학기별
이름을 바꾸거나 현재 학기의 수업을 초기화합니다.
이름은 앞뒤 공백을 제거한 뒤 화면에 보이는 문자 기준 1~60자이며, 이름을 정하지 않은
학기는 기본 제목을 사용합니다. 수업을 초기화해도 해당 학기의 이름과 기간은 보존합니다.

수업 블록을 누르면 과목명·교수·요일별 시간과 강의실·기본 강의 방식·메모를
읽는 상세 패널을 엽니다. **수업 수정**을 누르면 과목 전체를 편집하는 전체 화면
팝업이 열립니다.
신규 과목은 사용 빈도가 가장 낮은 초기 색을 고르며 기존 과목의 색은 유지합니다.

**기본 시간표**는 과목의 기본 강의 방식을 보여 줍니다. 관리 메뉴의 **주간 변경**을
선택하면 주 이동 도구가 나타나며, 수업을 눌러 해당 날짜의 휴강/강의 방식을
변경하거나 복원합니다. 같은 메뉴에서 **기본 시간표**로 돌아갑니다.
주간 변경은 학기 기간 안의 회차만 표시합니다. 그 안에서는 휴강과 영상 강의도
남겨 다시 변경할 수 있습니다. 기본 시간표는 방학에도 열어 볼 수 있습니다.

**강의 검색**은 하단 탭 바를 포함하지 않는 별도 검색 화면으로 이동합니다.
현재 시간표 격자 안에 검색 목록을 끼워 넣지 않습니다. 검색 화면의 뒤로가기와
시스템 뒤로가기로 시간표 탭에 돌아옵니다. 하단 탭에서 직접 여는 시간표 기본 화면에는
별도의 이전 버튼을 두지 않습니다. 넓은 화면의 상단은 시간표·빠른 보기·주/월/일·설정
순서로 우측에 붙여 배치하며 나머지 동작은 시간표 왼쪽에 둡니다. 휴대폰·태블릿의
좁은 화면에서는 기존 하단 전환 탭과 상단 설정을 유지합니다. 시간표·학사정보 안내도
빠른 보기·주/월/일과 같은 슬라이드 전환을 사용합니다.

강의 검색창은 목록을 스크롤해도 상단에 고정됩니다. 학사 정보의 캠퍼스는 처음 열 때의
기본 선택으로 사용하며, 대학명 옆 캠퍼스를 누르면 같은 대학의 다른 캠퍼스로 바꿀 수
있습니다. 지원 학교의 두 캠퍼스 강의에 서로 접근할 수 있습니다. 이 검색 필터는
저장된 소속 캠퍼스나 이미 추가한 수업을 바꾸지 않습니다. 캠퍼스 전환 시 검색어는
유지하고 학과 필터는 초기화합니다. 학과·이수구분·겹치는 강의 제외 필터를 제공하며 과목명, 과목코드와 분반, 교수명, 강의실, 이수구분으로 검색합니다.
한글 초성 검색과 여러 검색어 조합을 지원하고, 검색 결과는 정확히 일치하는 과목명·코드와
접두어가 일치하는 결과부터 보여 줍니다. 추가한 과목은 추가됨으로 표시합니다.

각 결과에는 **전공·전필·기초·전심·전선·교직·교양·일반·자격·MD** 등을 작은 텍스트와 고정색 점으로
표시합니다. 범주마다 같은 색을 밝은·어두운 테마에서 유지하며, 텍스트를 함께 표시해
색만으로 구분하지 않습니다. 공식 자료에 이수구분이 없는 항목은 추정하지 않고
미분류로 남깁니다. 분반은 강의명에 붙이지 않고 **과목코드-분반**으로 표시합니다
(예: `HAAH1212-1`).

검색 결과를 누르면 **해당 강의 항목이 목록 안에서 펼쳐집니다.** 과목명,
과목코드-분반, 이수구분, 시간·강의실과 교수 아래에 학과별 공식 이수구분과 학점,
비고, 시간 겹침, 강의 방식 선택과 추가 버튼을 표시합니다. 같은 항목을 다시 누르면
접히며 다른 강의를 누르면 그 강의가 펼쳐집니다. 별도 팝업이나 화면을 만들지 않으며,
검색 화면의 뒤로가기는 시간표 탭으로 돌아갑니다.

**비고**는 공식 강의표에 기재된 학년·학과·소속별 수강 제한 등을 원문 그대로
끝까지 표시합니다. 학과별 비고가 다르면 학과 이름과 함께 구분해 모두 표시합니다.
빈 비고를 수강 가능으로 추정하지 않습니다. 새로 추가한 강의는 비고를 수업 메모에도
보존하므로 기존 Drive 시간표 동기화를 통해 다른 기기에서도 확인할 수 있습니다.
기존 수업이나 사용자가 작성한 메모는 이 변경으로 덮어쓰지 않습니다.

공식 강의 시간이 비어 있거나 교시 근거가 충돌하는 과목도 검색 목록에서 제외하지
않습니다. 공식 시간 표기와 비고를 표시하고, 시간을 확인해 직접 추가하도록 안내합니다.
이 경우 잘못된 자동 배치를 막기 위해 검색 결과의 자동 추가 버튼은 비활성화합니다.

사용자가 대면·실시간 비대면·영상 중 기본 강의 방식을 직접 선택하고
**시간표에 추가**를 눌러야 저장합니다. 저장에 성공해도 상세는 펼친 상태로 유지하며
추가됨을 표시하고 중복 추가 버튼을 비활성화합니다. 이미 추가한 강의도 다시 펼쳐
비고를 읽을 수 있습니다. 실패하면 강의 방식과 상세를 유지해 다시 시도할 수 있습니다.
직접 수업 추가와 기존 수업 수정은 전체 화면 팝업을 유지합니다. 어두운 테마에서는
팝업에 `#495363`, 1.2 논리 픽셀 경계를 적용합니다.

시간 겹침은 경고만 표시하며, 사용자가 켠 경우에만 겹치는 강의를 제외합니다.
같은 요일의 아래 시간 경계 정책을 적용한 구간끼리 비교하므로 끝과 시작이 맞닿는
수업은 겹친다고 판정하지 않습니다. 저장된 영상 강의도 시간 충돌에서 제외합니다.

## 수업 시간 경계

시간표와 주·일간 스케줄의 수업 블록은 **매시 00분 또는 30분**에 시작·종료합니다.
원본 시작 시각은 이전 30분 경계로, 종료 시각은 다음 30분 경계로 맞춥니다.
이미 경계에 맞는 시각은 바꾸지 않습니다.

| 원본 수업 시간 | 시간표·스케줄 표시 |
| --- | --- |
| 09:00–09:50 | 09:00–10:00 |
| 09:00–10:15 | 09:00–10:30 |
| 09:30–10:45 | 09:30–11:00 |
| 23:00–23:50 | 23:00–24:00 |

50분짜리 수업도 한 시간 블록을 차지하므로 강의실 표시 공간이 불필요하게 줄지
않습니다. 강의실이나 제목 정보를 줄이는 방식으로 해결하지 않습니다. 직접 입력과
편집의 시간 목록도 00분·30분 단위이며, 하루 마지막 종료 시각은 24:00까지 지원합니다.

이 정책은 이미 저장된 수업에도 읽기·표시 시 적용합니다. 원본의 50분·75분 수업 시각은
자료와 저장 JSON에 그대로 보존하며, 이 표시 변경 때문에 기존 Drive 수업을 일괄
다시 쓰지 않습니다. 격자, 수업 상세, 날짜별 스케줄과 시간 충돌 판단에 같은 경계를
사용합니다. 시간 외의 항목만 편집하면 원본 시각을 유지하고, 사용자가 시간 자체를
변경한 경우 선택한 새 경계를 저장합니다.

## 강의 방식과 날짜별 예외

- 기본 방식: 대면 / 실시간 비대면 / 영상.
- 날짜별 한 회차: 기본값 사용 / 휴강 / 대면 / 실시간 비대면 / 영상.
- 회차 예외 키는 수업 시간 블록 ID와 현지 날짜입니다. 같은 과목이 같은 날
  두 번 진행돼도 각 회차가 독립적입니다.
- 대면·실시간 비대면만 스케줄에서 시간을 차지합니다. 휴강·영상은 제외합니다.
- 시간표 탭에서는 휴강·영상도 남겨 다시 수정할 수 있습니다.
- 기본값 사용을 선택하면 예외가 삭제되어 과목의 기본 방식을 다시 따릅니다.
- 학교 데이터의 교시/강의실 명칭을 이용해 강의 방식을 추정하지 않습니다.
  가져오기 전에 사용자가 직접 방식을 선택해야 합니다.

## 데이터 구조

학사 정보는 시간표 수업 문서와 분리해 `daily-sync-v2-settings.json`의
`academicProfile` 설정 필드로 저장합니다. 대학 식별자·이름·대학 구분·캠퍼스를
하나의 값으로 병합하는 LWW 필드이므로, 서로 다른 기기에서 학교를 변경해도 대학과
캠퍼스가 다른 선택에서 뒤섞이지 않습니다. 로컬 `academicProfile.v1`은 설정 캐시입니다.
자료에 표시하는 학교와 학교별 기능 지원 여부는 이 프로필에서 결정합니다.

`TimetableClass`와 `ClassMeeting`은 일반 일정과 분리된 모델입니다.
`TimetableStore`는 `daily.timetable.v1` 키에 수업·회차 예외·학기별 이름·기간과
기기별로 선택한 학기를 보존합니다. 수업·이름·기간은 Drive 데이터의 로컬 캐시입니다.
이전 버전에서 이 기기에만 저장했던
시간표도 유지하며 새 동기화 형식으로 이관합니다. 저장 요청은 직렬화하고
저장 성공 이후에만 화면 상태를 바꿉니다. 기존 데이터 읽기 실패 시 원본을
덮어쓰지 않습니다.

`daily-sync-v2-timetable.json`에는 현재 선택한 학기뿐 아니라 모든 학기의
시간표를 저장합니다. 수업은 ID별 수정 시각을 비교해 최신 변경을 병합하고,
삭제 기록(tombstone)을 함께 보존해 다른 기기에 남은 수업이 되살아나지 않게 합니다.
날짜별 회차 예외는 해당 수업과 함께 동기화하며 학기별 이름과 기간도
독립된 레지스터로 동기화합니다. 선택한 학기는 기기 내 UI 상태입니다. 이전 문서의
`activeTerm`은 호환성을 위해 보존하지만 화면에 적용하거나 새 선택으로 갱신하지 않습니다.
일반 일정 JSON에 수업을 섞거나 기존 이벤트 전체를 다시 올리는
방식은 사용하지 않습니다.

로컬 저장 형식은 `version: 1`을 유지하고 `sync`에 동기화 문서·기기 ID·대기
상태를 함께 저장합니다. Drive 전송 파일은 `schemaVersion: 2`, `type: timetable`
봉투 안에 `schemaVersion: 1`인 시간표 문서를 담습니다. `termPeriods`는 선택 필드이며
시작일·종료일을 날짜 문자열로 보존합니다. 공식 기본 기간도 기존 수정/삭제보다
우선하지 않는 무시각 초기값으로 이관합니다. 충돌은 UTC
수정 시각, 같은 시각일 때 삭제 우선, 기기 ID, 정규화한 JSON 순으로 결정해
두 기기에서 같은 결과를 냅니다.
학교 목록에서 추가한 수업은 자료 ID와 학년도·학기를 기준으로도 식별해 기기별
UUID가 달라도 같은 분반이 중복되지 않게 합니다. 수정 시각이 없던 기존 자료는
현재 시각으로 덮어쓰지 않고 이관해, 다른 기기의 최신 변경보다 우선하지 않습니다.

로컬 변경은 동기화 대기로 표시하며, Google Drive 연결 전이나 오프라인에서도
보존됩니다. 연결·앱 재개·시간표 변경 등 기존 동기화 흐름에서 다시 시도합니다.
화면의 안내는 동기화 기능과 대기 여부를 나타내며 실제 업로드 성공을 대신하는
표시가 아닙니다. 실제 계정 간 왕복 검증 여부는 최신 `AGENT_MEMORY.md`의 검증
기록을 확인합니다.

`classOccurrences`가 현지 날짜·요일·학기 기간을 매핑하고 스케줄 제외 여부를 판단합니다.
`TimetableSchedule`은 스케줄 렌더러에만 임시 읽기 전용 `CalendarEvent`를 전달합니다.
일반 일정과 동일한 겹침 배치를 사용하지만 수업의 드래그/완료 변경은 허용하지 않고
수업 상세와 회차 변경을 엽니다. 원본 일정 쿼리와 검색에는 이 투영을 넣지 않습니다.

`UniversityCourse`는 입력 자료입니다. 사용자가 추가한 뒤에는 독립된
`TimetableClass` 사본이므로 목록 변경/제거가 수업을 삭제하거나 수정하지 않습니다.
학교/캠퍼스/학년도/학기/학수번호/분반의 sourceId로 중복 추가를 차단합니다.

## 개발자 데이터 갱신

`assets/timetable/catalog.json`에 표준 JSON 경로를 등록합니다.
각 파일은 schemaVersion, 캠퍼스, 학년도/학기, 자료 URL·기준일·SHA256,
원본 행 수와 정규화한 과목들을 포함합니다. 원본 시간은 `schedules`, 학과별 이수구분은
`departmentClassifications`에 보존합니다. 강의 방식 필드를 넣지 않습니다.
앱은 파일 구조·수업 시간·중복 sourceId를 검사하며 실패를 빈 목록으로 숨기지 않습니다.

공식 PDF의 표 구조를 변환하는 도구:

```sh
python -m pip install pdfplumber
python tool/timetable/import_sangmyung.py \
  --campus seoul --year 2026 --semester 2 \
  --pdf source.pdf --source-url '공식 PDF URL' \
  --published-date 2026-09-23 --output assets/timetable/smu-seoul-2026-2.json
```

도구는 알 수 없는 행·시간 표기·이수구분·충돌하는 수업 정보를 만나면 중단합니다.
학과별 중복은 학수번호/분반으로 병합하고 모든 학과와 원본 쪽수를 보존합니다.
새 학기 적용 시 PDF 표와 교시 안내를 다시 확인한 뒤 테스트합니다.
