## 복구·정정 사항

1. **현재 상태의 위치:** 9월 11~24일 기록은 파일 위쪽에 이미 존재했다.
   맨 위에 현재 인계 요약과 이 대조표 링크를 추가하고, 9월 7일의 현재 상태
   제목을 역사 기록으로 변경했다. 끝에서도 최신 요약으로 이동할 수 있다.
2. **작업·경로:** 저장소는 날짜 폴더 없는 현재 경로로 이동했다. 과거의 절대
   경로는 당시 증거로 보존하되 자료 조회는 현재 저장소의 같은 상대 경로부터 한다.
3. **Play 정정:** 기존 키 등록을 단정한 안내가 후속 화면에서 철회됐는데 문서에
   남아 있었다. 재설정이 확정된 다음 단계라는 문장을 삭제했다. 공개 PEM은
   그대로 유효한 준비 자료지만, 업로드 성공이나 재설정 접수 증거는 없다.
4. **학사일정 정정:** 등록된 소스는 `lib/core/di/app_providers.dart`의
   `SangmyungAcademicSource` 하나다. 정확한 출시 문구는
   “상명대학교 학사 일정 가져오기 및 분류 색상 설정 추가”다.
5. **배경화면 증거:** 9/16 사용자 실행의 완료 기록, 현재 선택된 사진 배경,
   저장 이미지와 생성 PNG의 SHA-256 일치 확인을 보완했다. 당시 확인은 읽기
   전용이었고 `PhotosPosterProvider`의 실제 화면 렌더링 문제는 남았다.
   9/24에는 사용자가 단축어 추가·실행·배경 변경 테스트를 명시적으로 거절했다.
6. **미해결 항목:** #65 제외, #67 완료 근거 없음, 날씨 알림 보류, 지원하지 않는
   두 대학, Play 불일치, 심사 계정 필드 문제 및 실제 모바일/다기기 검증을 유지했다.
   #63 제외는 9/16 승인으로 바뀌었으며 #69는 사용자 요청으로 삭제된 이슈다.
7. **전역 Codex 메모리:** 과거 요약의 v1 동기화·Windows 3.3.1·3.4.0 제출
   중심 상태를 현재 사실로 사용하지 않도록 별도 정정 노트를 추가했다.
   자동 관리되는 요약 원문은 직접 수정하지 않았다. 향후 작업은 저장소의
