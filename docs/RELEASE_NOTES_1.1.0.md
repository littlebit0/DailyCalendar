# Daily 1.1.0

Daily 1.1.0은 일정을 더 쉽게 훑어보고, 여러 기기에서 더 안정적으로 이어 쓸 수 있도록 다듬은 업데이트입니다.

## 주요 업데이트

- 주간, 월간, 일간 보기를 전환할 수 있도록 추가했습니다.
- 앱을 열었을 때 주간 보기를 먼저 확인할 수 있도록 기본 흐름을 개선했습니다.
- 월간 달력에서 일정 제목이 더 잘 보이도록 표시 밀도와 배너 가독성을 개선했습니다.
- 일정 검색, 분류 필터, 공휴일 표시 필터, D-day 전용 보기 옵션을 추가했습니다.
- 날짜를 드래그하거나 길게 눌러 여러 날짜를 선택한 뒤 일정을 추가할 수 있습니다.
- 반복 일정 수정과 삭제 시 `이 일정만`, `이후 일정`, `전체 반복 일정` 중에서 범위를 선택할 수 있습니다.
- 일정마다 URL, 날씨 메모, 민감 일정 여부를 따로 기록할 수 있습니다.
- 앱 잠금 PIN, 민감 일정 제목 숨김, 민감 일정 알림 숨김 설정을 추가했습니다.
- Google Drive AppData 동기화 상태를 확인하고, 필요할 때 바로 다시 동기화할 수 있도록 개선했습니다.
- Android 홈 화면에서 사용할 수 있는 월간, 오늘, D-day 위젯 진입점을 추가했습니다.
- Windows에서는 창을 닫아도 트레이에서 계속 실행되며, 트레이 메뉴에서 미니 캘린더를 열 수 있습니다.
- macOS에서는 마지막 창을 닫아도 앱이 바로 종료되지 않도록 동작을 맞췄습니다.

## 개선된 안정성

- Android에서 Google 로그인 창을 닫거나 응답이 지연될 때 원시 오류 대신 이해하기 쉬운 안내가 표시됩니다.
- 일정 삭제, 반복 일정 편집, 동기화 상태 갱신 흐름을 더 자연스럽게 정리했습니다.
- iOS, iPadOS, macOS, Android, Windows가 같은 Flutter 화면 구조를 공유하도록 UX 흐름을 맞췄습니다.

## 설치 파일 안내

- `daily-android-1.1.0.apk`: Android 기기에 직접 설치할 때 사용합니다.
- `daily-android-1.1.0.aab`: Google Play Console 제출용 파일입니다.
- `daily-windows-1.1.0.zip`: Windows에서 사용하는 권장 배포 파일입니다.
- `daily-windows-1.1.0.exe`: Windows 실행 파일입니다.

Windows에서는 `daily-windows-1.1.0.zip` 사용을 권장합니다. Windows 앱은 실행 파일 외에도 함께 포함된 `data` 폴더와 DLL 파일이 필요합니다.

## 참고 사항

- iOS와 macOS 설치 파일은 이번 릴리즈에 포함되어 있지 않습니다. Apple 플랫폼 배포는 macOS, Xcode, Apple Developer 설정이 필요합니다.
- Android 위젯은 이번 버전에서 앱으로 빠르게 들어가는 진입점부터 제공하며, 위젯 안에서 실제 일정 내용을 바로 보여주는 기능은 이후 업데이트에서 개선할 예정입니다.
- Google Drive 동기화는 사용자의 Google Drive AppData 영역에 앱 전용 백업 파일을 저장합니다. 앱 잠금 PIN은 기기 안에만 저장되며 Google Drive로 동기화하지 않습니다.
