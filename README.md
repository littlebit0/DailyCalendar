# DailyCalendar

일정을 빠르게 기록하고 여러 기기에서 이어서 사용하는 개인 캘린더

월간, 주간, 일간, 연간 보기로 일정을 관리합니다. 계정 없이 쓸 수 있고, Google 계정을 연결하면 일정과 설정을 기기 사이에 동기화합니다.

iPhone과 iPad는 App Store에서 `DailyCalendar`를 무료로 설치합니다. App Store 출시는 GitHub 릴리스와 별개입니다. 다른 플랫폼은 [GitHub Releases](https://github.com/littlebit0/DailyCalendar/releases/latest)에서 4.1.1 파일을 받습니다.

GitHub의 IPA와 DMG는 App Store 제출 파일이 아닙니다. 미서명 IPA는 따로 서명하지 않으면 iPhone에 설치할 수 없고, 재서명하면 Sign in with Apple 같은 entitlement가 빠질 수 있습니다. 일반 사용자는 App Store 설치본을 쓰세요.

Android는 3.4.0에서 서명키를 바꿨습니다. 이전 키를 쓸 수 없어 새 배포 키를 만들었기 때문에 3.3.1 APK 위에 덮어쓰기 설치가 되지 않습니다. 앱을 삭제하면 로컬 데이터도 지워지므로, 삭제 전에 데이터를 백업하고 복원할 수 있는지 확인하세요. 새 키의 Google OAuth 등록은 2026-09-07에 마쳤고, 실제 스마트폰 로그인은 아직 검증하지 않았습니다. 설정 반영에 시간이 걸릴 수 있으며, 로컬 모드는 계정 없이 쓸 수 있습니다. 자세한 내용은 [서명 및 전환 안내](docs/ANDROID_SIGNING.md)에 있습니다.

Windows는 `setup.exe` 설치를 권장합니다. 설치형 Release 앱은 시작할 때 최신 GitHub 릴리스를 확인하고, 새 Windows 설치 프로그램이 있으면 자동으로 업데이트합니다.

### Linux

4.1.1은 AMD64와 ARM64 설치 파일을 제공합니다. 자동 APT 채널도 4.1.1로 업데이트됩니다.

```sh
sudo apt install ./daily-linux-4.1.1-1-amd64.deb
```

Intel/AMD PC는 amd64, ARM64 PC는 arm64 파일을 씁니다. 빌드 기준은 amd64가 Ubuntu 22.04+, arm64가 Ubuntu 24.04+입니다.

Ubuntu/Debian 데스크톱용 `.deb`를 한 번 설치하면 Daily 전용 타이머가 약 6시간마다 서명된 업데이트를 확인합니다. 앱이 실행 중이거나 검증에 실패하면 업데이트를 미루고, 일정과 설정은 지우지 않습니다. 설치할 때 앱을 자동으로 실행하지 않습니다.

두 아키텍처의 Release 빌드와 공개 APT 다운로드·해시 검증을 마쳤고, amd64에서 설치·자동 업데이트·제거와 사용자 파일 보존을 검증했습니다. 실제 데스크톱 UI, Google 로그인, 알림 전달은 아직 실사용 검증 전입니다. Linux에는 Siri, Apple 위젯, AlarmKit이 없습니다. [설치·업데이트 구조 및 Linux 지원 범위](docs/LINUX_DISTRIBUTION.md)를 참고하세요.

## 처음 사용

앱을 처음 열면 단계형 온보딩이 시작됩니다. 계정 없이 로컬 모드로 바로 쓸 수 있고, 일정은 기기의 로컬 데이터베이스에 저장됩니다.

여러 기기에서 쓰려면 Google 계정을 연결합니다. iOS와 macOS에서는 Sign in with Apple도 쓸 수 있습니다. 연결하면 일정과 설정이 Google Drive AppData에 백업되고 다른 기기와 동기화됩니다.

학사일정이나 학교 시간표를 쓰려면 지역 지도와 이름·초성 검색으로 대학을 고릅니다. 지역이 다른 분교는 선택한 지역에 맞게 등록됩니다.

## 4.1.1 변경 사항

- Google Drive 동기화가 빨라졌습니다. 여러 파일을 동시에 주고받고, 내용이 같은 파일은 다시 받지 않습니다.
- 동기화 중 캘린더가 깜빡이거나, 보던 위치가 바뀌거나, 동기화 배너 때문에 화면이 튀던 문제를 고쳤습니다.
- 일정 알람 시각을 여러 개 고를 수 있고, 자정을 넘는 일정의 다음 날 표시를 일정마다 정할 수 있습니다.
- 요일을 지정한 주간 반복을 시작일 요일부터 계산합니다. 옮기거나 나눈 반복 일정도 같은 간격을 유지합니다.
- 하루 일정 시트의 닫기·날짜 넘김과 일정 추가·수정 팝업의 버튼 배치를 고쳤습니다.
- 4.1.0에서는 잊모기 탭, 일정 템플릿, 71개 대학 학사일정 1차 지원, 원격·시간 미정 강좌 표시가 추가됐습니다.

> [!NOTE]
> Drive v2를 유지하며 DB 스키마는 15입니다. 4.1.1은 Drive 일정 파일에 새 값을 쓰므로 같은 계정의 모든 기기를 4.1.1로 업데이트하세요.

## 할 수 있는 일

### 캘린더와 일정

- 월간, 주간, 일간, 연간 및 빠른 보기
- 주간·일간 시간표형 보기와 종일 일정 표시 제어
- 일정 추가, 수정, 삭제, 검색 및 분류 필터
- 모든 사용자 일정의 Todo 완료 상태와 빠른 보기·위젯 체크
- 반복 일정, 연속 일정, D-day, 음력과 대한민국 공휴일
- 날짜 범위 드래그 입력과 일정 날짜 이동·날짜별 수동 순서
- 외부 캘린더 가져오기
- 선택형 기상청 날씨 예보와 지역 설정
- 위치, 지도 바로가기, 링크, 메모와 날씨 정보

### 알림과 위젯

- 일정별 복수 알림과 아침 브리핑
- iOS 26 이상 일정별 시스템 알람
- iPhone, iPad 및 macOS의 오늘 일정·주간·월간·D-day 위젯
- Android 월간·오늘 일정·D-day 홈 화면 위젯과 위젯 Todo 체크
- Windows 트레이 미니 캘린더와 일정 Todo 체크
- 위젯 Todo 체크와 앱 테마에 따른 자동·화이트·다크 표시
- iPhone 및 iPad 잠금화면 위젯
- 일정을 바꾸면 알림, 알람, 위젯이 바로 갱신됨

### Siri와 자동화

- iOS 및 macOS Siri/App Intents로 일정 조회, 검색, 추가, 수정, 삭제
- 일정을 바꾸기 전에 필수 정보를 확인하고 사용자 승인을 받음
- 설정에서 날짜별 Siri 실행 기록과 상세 결과 확인
- Siri 작업 결과를 캘린더, 위젯, 알림, 동기화 상태에 바로 반영

### 개인 설정

- 한국어, 영어, 일본어, 중국어 번체
- 시스템 언어 자동 적용 및 앱별 언어 선택
- 라이트·다크 테마와 반응형 글자 크기
- Apple 플랫폼과 같은 단계형 온보딩, 빠른 보기와 그룹형 설정 화면
- 사용자 분류, 직접 선택 색상, 분류 순서와 일정 정렬 우선순위
- 공휴일 분류 색상과 선택형 공휴일 날짜 배경
- PIN 없음 보호, Daily PIN 및 Apple 시스템 인증 앱 잠금

## 대학 학사일정과 시간표

학사일정과 학교 시간표는 대학을 차수로 나누어 다시 지원합니다. 대상은 대학알리미 2026 공시대상 4년제 대학(앱 대학 목록 기준)과 신학대입니다. 학사일정은 기존 연동을 모두 제거했고 1차 대학부터 새로 연결합니다. 학교 시간표 검색은 아래 10개 대학만 유지하고, 나머지 대학의 시간표 원자료는 제거했습니다. 사용자가 이미 저장한 일정·시간표와 직접 추가한 수업은 그대로 유지합니다.

현재 학교 시간표 검색 지원(1차 포함): 단국대학교, 부산대학교, 상명대학교, 서울대학교, 세종대학교, 아주대학교, 이화여자대학교, 인하대학교, 중앙대학교, 홍익대학교.

주·일간 캘린더에는 해당 학기 기간에만 수업을 표시합니다.

| 차수 | 대학 수 | 범위 |
| --- | ---: | --- |
| 1차 | 72 | 지금 진행하는 지원 대상 |
| 2차 | 60 | 1차 이후 지원 |
| 3차 | 44 | 2차 이후 지원 |
| 4차 | 25 | 신학대 |
| 5차 이후 | 140 | 전문대 계열(전문대학·기능대학·전공대학·사내대학), 나중에 지원 |

1·2차 조정에는 대학알리미 '우리대학경쟁력'의 학부 전체 재학생 수(2025-04-01 기준, 캠퍼스 합산)를 참고했습니다. 대학 목록의 출처는 [대학 목록 출처](docs/UNIVERSITY_DIRECTORY_SOURCES.md)에 있습니다.

## 데이터와 동기화

일정과 설정은 기본적으로 기기의 로컬 SQLite 데이터베이스에 저장됩니다. Google 연결은 선택 사항이며, 앱 전용 `appDataFolder`만 쓰고 일반 Google Drive 파일은 읽거나 고치지 않습니다. 별도의 일정 백엔드 서버는 없습니다.

Google Drive에는 일정마다 파일을 따로 두고 설정은 파일 하나에 저장합니다.

- 일정을 만들거나 고치거나 지우면 바뀐 일정만 업로드합니다.
- 삭제 상태는 tombstone으로 다른 기기에 전파합니다.
- 충돌은 일정별 생성·수정·삭제의 최신 UTC 변경 시각으로 병합합니다.
- 분류 이름·색상 같은 설정은 항목별로 병합하고, 조건부 쓰기로 동시 변경을 막습니다.
- 삭제하지 않은 과거 일정은 보존하고, 만료된 삭제 일정만 최소 기록으로 정리합니다.
- 종일 일정은 날짜 전용 필드로 저장해 시간대 때문에 날짜가 밀리지 않습니다.
- 앱 시작, 로그인, 포그라운드 복귀, 수동 요청 때 필요한 동기화를 합니다.
- 통합 로그아웃과 로컬·클라우드 데이터 삭제 흐름을 제공합니다.

LMS 로그인 정보는 다른 기기로 동기화하지 않고 일정만 동기화합니다. 학교 정책에 따라 다른 기기의 LMS 세션이 종료될 수 있습니다.

광고, IDFA, 광고 측정, 데이터 브로커 공유, 앱 간 사용자 추적은 쓰지 않습니다. 익명 사용성 분석은 기본으로 꺼져 있고, 설정에서 직접 허용해야 작동합니다. 분석 데이터에는 일정 내용, 검색어, 계정 정보, 광고 식별자, 지속적인 기기 식별자가 들어가지 않습니다.

자세한 내용은 [개인정보 처리방침](docs/PRIVACY_POLICY.md), [개인정보 및 보안 설계](docs/PRIVACY_AND_SECURITY.md), [Google Drive 동기화 설정](docs/GOOGLE_DRIVE_SYNC_SETUP.md)에 있습니다.
